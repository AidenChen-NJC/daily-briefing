OpenRouter 拿到的不只是錢，是 Google 的情報協議

! CapitalG 領投一個讓開發者繞過 Gemini 的平台，Google 用投資換跨競品推理流量數據，這是今天最值得追的地緣政治信號。
事實背景

OpenRouter 是 2023 年成立的 LLM API 聚合與路由平台（路由層，routing layer，根據成本、品質、延遲動態挑選模型）。5 月 26 日完成 Google CapitalG 領投的 1.13 億美元 B 輪融資，估值升至 13 億美元，較上輪翻倍。平台目前月處理 100 兆個 tokens（token throughput，LLM 流量的標準計量單位），對比六個月前的每週 5 兆，半年成長五倍。共同投資人包含 Nvidia、ServiceNow、MongoDB、Snowflake、Databricks，以及既有投資人 a16z，覆蓋 400 個以上模型，橫跨 Anthropic、Google、OpenAI、xAI、DeepSeek。

So What?

CapitalG 領投一個讓開發者跳過 Gemini 去選 DeepSeek 的平台，不是慈善。OpenRouter 每週 25 兆 tokens 的跨模型流量，是市場上最完整的「哪個 workload 跑哪個模型」行為數據集，Google 用投資換取這份競品情報，代價遠低於自建。輸家是 Anthropic 和 OpenAI，他們的推理流量流過 OpenRouter 時，競爭情報等於對 Google 透明化。

值得追問
  1. CapitalG 領投一個讓開發者繞過 Google 自家模型去選 DeepSeek 和 Anthropic 的平台，Google 到底是在對沖自己輸，還是在用投資換取跨競品的推理流量數據？
  2. 如果 Databricks、Snowflake、ServiceNow 同時是投資人又是潛在競品，他們各自在自家平台內建模型路由的那天，OpenRouter 的企業客戶留存靠什麼擋？

小米 99% 降價只對一種工程師有意義

事實背景

5 月 27 日零點起，小米對 MiMo-V2.5 系列 API 實施永久性降價，最高降幅 99%。新定價每百萬 tokens：MiMo-V2.5 cache hit input（prompt caching，把重複的 prompt 前綴緩存可大幅降價）0.0028 美元、cache miss input 0.14 美元、output 0.28 美元；Pro 版分別為 0.0036、0.435、0.87 美元。同步取消 context length 分級，所有長度同價。訂閱制 Token Plan（API 額度包）credits 提升五到八倍，未用完額度全數重置。對標陣營為 DeepSeek、Qwen、Kimi 等中國模型廠。

So What?

0.0028 美元的 cache hit 吸引力完全依賴高命中率，但多租戶環境下 KV cache 駐留需要可預測的 prompt 前綴重疊，通用 API 場景中很難穩定維持。若命中率低於 60%，有效定價會向 0.14 美元的 cache miss 靠攏，「99% 降價」的行銷敘事就只對高重複度的 batch workload（如文件摘要流水線）成立，低重複度的互動式 chatbot 幾乎感受不到差異。真正受益的工程師很具體：跑大量重複前綴的批次任務、對延遲容忍度高、且願意換 SDK 的那群人。

值得追問
  1. Cache hit 壓到 0.0028 美元每百萬 tokens 意味著 KV cache 必須長期駐留記憶體，小米在多租戶環境下的 cache eviction 策略能否在高併發下維持這個命中率？
  2. 小米做這個定價的真正恐懼是不是 DeepSeek 和 Qwen 已經鎖住了中國開發者的預設 SDK，所以只能用負毛利買通路入口？

Hassabis 列出 4 個問題，卻沒給任何一個里程碑

事實背景

Google DeepMind CEO Demis Hassabis 在 Google I/O 後接受 Rundown 獨家視訊訪談，把 AGI（Artificial General Intelligence，通用人工智慧）到達時間定在 2030 年正負一年，並明確列出四個未解問題：world physics（模型對物理世界的內建理解）、memory（長期記憶缺失）、consistency（相同輸入不產生相同輸出）、continual learning（部署後無法持續更新權重）。DeepMind 計劃先聚焦腫瘤學與免疫學的藥物研發應用。

So What?

Hassabis 列出的四個未解問題，沒有一個附帶可外部驗證的 benchmark 或時間節點。這與 AlphaFold 的情況形成對比，蛋白質結構預測有 CASP 競賽作為客觀里程碑，而 AGI 的四個維度目前沒有等效的產業標準測試集。對 Alphabet 股東而言，這等於批准了一張沒有交付條件的資本支出授權，DeepMind 的資本效率辯護只能靠 Gemini 的商業表現撐，而不是 AGI 進度。

值得追問
  1. Hassabis 每次把 AGI 時間表往前拉一年，Google 給 DeepMind 的資本支出預算就多拿一輪批准。Alphabet 的股東該問的是：這四個「未解問題」中哪一個有可驗證的里程碑，還是這只是一張無限期的空白支票？
  2. Memory 和 continual learning 這兩項如果被任何一家 lab 先突破，現有所有賣 RAG pipeline 和 context management 的公司是不是一夜歸零？

a16z 用活動量指標替 portfolio 公司撐估值

事實背景

a16z partner Jennifer Li 團隊發表文章，核心論點是：AI 應用層不會被 lab 全部吃光，但會分裂為「黃磚路」（Yellow Brick Road，labs 直接搶佔的水平通用 agent 市場）和「Oz 其他地方」（垂直、多步驟、需人工審核的 workflow，labs 結構性進不來）。文章舉出 portfolio 公司 11x（AI sales 工具）的成果：客戶 reply rate 提升四倍，「為 F1000 機構一天產生比整個業務部門一個月更多的 sales opportunities」。另一個案例是 FurtherAI，負責保險核保 workflow 自動化。

So What?

「一天產生比業務部門一個月更多的 pipeline」是活動量指標（activity metric），不是結果指標（revenue metric）。若 close rate 因大量低品質 outreach 從正常 B2B 水位的 15 到 20% 下滑到 3 到 5%，銷售效率可能沒有提升甚至倒退。a16z 沒有公開 11x 客戶的 qualified pipeline rate 或實際成交收入數字，這個案例目前只能算作「活動量放大」的證明，而非「revenue impact」的證明。

值得追問
  1. 11x 說客戶 reply rate 提升四倍，但那些 reply 的成交轉換率和 ACV（Annual Contract Value，年度合約金額）是多少？還是只是幫客戶製造更多低品質 pipeline 讓銷售團隊更忙？
  2. a16z 一邊跟投 OpenRouter 押注模型路由層，一邊告訴 LP 垂直 AI 才是安全地帶。這兩個論點的資本配置邏輯互相矛盾，到底哪一個才是 a16z 真正在加碼的方向？

AI 招聘工具的真正風險不是偏見，是集中度

事實背景

Stanford 主導、Chapman 與 Northeastern 共同完成的研究，分析 2018 至 2022 年間 156 個雇主、1,700 個職缺、3.4 百萬申請者的 400 萬份申請，全部經由 Pymetrics（被 Harver 收購的 AI 招聘平台，用神經科學迷你遊戲評估候選人）篩選。結果顯示 10.62% 的職位對黑人申請者有 adverse impact（不利影響，美國 EEOC 的招聘歧視法律術語），5.32% 對亞裔，26% 的黑人候選人實際受影響。更關鍵的發現：42 個模型在不同雇主間共用，4% 申請 10 個職位的人全數被拒，顯著高於各雇主獨立決策應有的機率。論文「Algorithmic Monocultures in Hiring」（演算法單一文化，借自生物學單一種植的脆弱性概念）將於 ACM FAccT 發表。

So What?

42 個共用模型的 Pymetrics monoculture，和現在所有招聘 AI 平台共用 OpenAI text-embedding-3 或 Anthropic embedding 的情況相比，集中度是指數級放大而非縮小。2018 至 2022 年是 42 個專用模型跨 156 家雇主，現在可能是兩到三個底層 embedding 模型跨數千家雇主。任何存在於 OpenAI embedding 層的性別或種族偏差，會以 Pymetrics 案例中 monoculture 乘數的方式放大到整個就業市場。這是研究本身沒有說出來、但最重要的結論。

值得追問
  1. 42 個共用模型造成 monoculture 效應，但這個機制跟當前 LLM-based 招聘工具共用同一個 OpenAI embedding 層的集中度比起來，風險是更小還是指數級放大？
  2. 現在賣 AI 招聘工具的 HireVue、Eightfold 可以用「那是舊產品的問題」擋掉這份研究，但他們自己的 adverse impact 數據敢公開嗎？

中國鎖住 AI 人才，歐洲和東南亞市場拱手相讓

事實背景

Bloomberg 5 月 26 日獨家報導：中國政府要求 Alibaba、DeepSeek 等私營 AI 企業的部分核心人員（含創辦人、研究員、資深高管）出國前須取得政府核准。此舉被描述為「擴大管制」，因為 2025 年 12 月已對部分 DeepSeek 高層實施，更早有 Manus（中國通用 agent 產品）兩位共同創辦人被禁止出境的先例。中國政府已把頂級 AI 人才定位為「國家安全資產」，套用過去保留給核子科學家與國有企業高管的限制框架。

So What?

無法派 senior engineer 做 forward-deployed（客戶現場部署）工作，直接切斷中國 AI 公司在歐洲和東南亞企業市場的進入能力。企業級 AI 部署通常需要三到十二個月現場整合，遠端支援幾乎不可行。結構性受益者是在 AWS、Azure、GCP 上跑 OpenAI 或 Anthropic 的美國系系統整合商，以及有本地 forward-deployed 能力的 Palantir 和 ServiceNow。DeepSeek 的開源模型可以繞過這個限制，但閉源中國模型的企業銷售等於被切斷海外落地能力。

值得追問
  1. 人才管制讓中國 AI 公司無法在海外部署 senior engineer，那些靠中國模型降價邏輯建立的全球推理成本模型，是不是少算了「技術支援斷供」這層隱性成本？
  2. 如果我是一家在新加坡設點、專門挖中國 AI 人才的獵頭公司，這個政策是讓生意歸零，還是反而讓「已經在海外」的中國 AI 人才身價暴漲成為護城河？
