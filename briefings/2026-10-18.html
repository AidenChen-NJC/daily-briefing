Replit 換掉 Claude 預設，等於當眾兌現了 Anthropic 招股書最怕的那條風險

事實背景

Replit 是一個讓開發者直接在瀏覽器用自然語言生成應用的 vibe coding 平台，其共同創辦人兼 CEO Amjad Masad 在 TechCrunch Disrupt 2026（10-13 至 10-15）上被問到 Anthropic 合作狀況時，先說已不再合作、後澄清為「Claude 仍可選用，但 OpenAI 現在是 Replit Agent 的 preferred partner 與預設模型」，理由是成本、合作關係與效能，他稱 OpenAI 在內部 benchmark 上於 vibe coding 表現較佳。這句話是在回應 Anthropic 營收放緩的問題時說出的，落在 Anthropic 預計 11 月 IPO 前一個月。Replit 的企業合約占比從去年約 2% 升至今年約 15%，B2B 已超過 50%，NRR（net revenue retention，既有客戶一年後的營收留存率）超過 400%，ARR 未揭露。

So What?

Masad 自己說多數用戶不改 default model（平台預設模型，多數用戶不會手動切換），這一句話直接說明 Claude 留在選單上只是公關緩衝，Anthropic 在 Replit 的實際 API 呼叫量已在崩跌。這次事件的殺傷力不在「換了模型」，而在於它發生的時間點：Masad 是在被問到 Anthropic 營收放緩時主動說出 Replit 曾是其前五大客戶，等於把招股書裡「客戶集中度」這條風險因子當眾兌現了一次。OpenAI 拿下的是一個鎖定 vibe coding 高速增長垂直的分發前台，是本局真正的贏家。

值得追問
  1. Anthropic 11 月 IPO 招股書裡的客戶集中度風險，現在少了 Replit 這個「前五大」，剩下四家裡有幾家也在跟 OpenAI 談預設切換？
  2. Replit 說導入企業 12 個月內支出增 400%、NRR 超過 400%，但企業營收占比才從 2% 升到 15%，這代表企業客戶的絕對數量極少，真正撐 ARR 的還是個人 vibe coder，那 OpenAI 給了什麼 volume discount 才讓換預設這件事在單位經濟上成立？

AI 算力的死亡螺旋：Anthropic 越有效率，CoreWeave 的債就越危險

事實背景

CoreWeave 是一家專門出租 GPU 算力的 neocloud，其無擔保債的殖利率在 10-13 觸及 15%，當週股價跌逾 22%，至 $63.25。CoreWeave 的季利息支出從一年前的 $2.67 億升至 $6.40 億，Q3 指引進一步上修至 $8.60 億至 $9.40 億，backlog 達 $1,040 億。需求端同一週，FT 報導 Anthropic Q3 營收 $168 億，季增約 45%，較前一季的約 147% 大幅放緩，且首度實現 adjusted profitability，每 $1 算力支出產生 $1.70 營收。Alphabet 投資長 Ruth Porat 同期反駁「AI 資本大毀滅」論點，確認 2027 年 capex 將「significantly more」，四大 hyperscaler 今年 capex 預估合計逾 $7,200 億。

So What?

這個事件裡有一個結構性邏輯連股票分析師都在迴避：Anthropic 的推理效率越高，每塊營收需要的租用算力就越少，CoreWeave 的 backlog 在合約到期後就面臨被殺價或縮量的壓力。而 CoreWeave 的利息支出曲線從 $2.67 億翻到 $6.40 億再到指引 $9.40 億，全押在「需求會一直夠快」這個假設上。Deutsche Bank 和 Cantor 喊買，但債市比他們早一步把這件事定價進 15% 的殖利率裡。

值得追問
  1. Anthropic 每一美元算力支出產生 $1.70 營收，代表 lab 端推理效率每提升一個世代，CoreWeave 的 backlog 在合約到期續約時會被殺價，CoreWeave 拿 GPU 做抵押的債務結構能承受客戶單位算力需求持續下降嗎？
  2. Alphabet Porat 說「by the time you need it, it's too late」來合理化 capex 翻倍，但她真正害怕的 GTM 威脅是什麼？是 neocloud 搶走 AI lab 客戶，還是開源模型讓推論成本崩跌、讓預購的產能根本用不完？

DeepSeek 1017 的真正目的不是贏 benchmark，是搶騰訊工具裡的預設位

事實背景

DeepSeek 10-17 發布 V4.1-Flash-1017，API 呼叫方式與價格不變。自報數據：Deep-SWE v1.1 通過率 74.2%，略高於 Anthropic Opus-5 的 74.0% 與 OpenAI GPT-5.6 Sol 的 73.0%；Terminal-Bench 4.0 從 31.2 升至 42.3；Codeforces rating 達 3,471，超越已退役旗艦 V4-Pro 的 3,348。DeepSeek 同時建議搭配自家 harness（包住模型的 agent 執行框架）dsh v0.2.1-rc.1 以上版本，並對騰訊 CodeBuddy 與 WorkBuddy 做了優化。WorkBuddy 允許切換混元、DeepSeek、GLM、Kimi 等多個模型。DeepSeek Harness 於 8 月 13 日以 MIT 授權開源，8 天內累積約 197,000 GitHub stars，模型權重同樣為 MIT 授權。

So What?

對標的是已被 Opus 5.5 取代的舊 Opus 5，0.2% 的 Deep-SWE 差距在自報數據裡是統計雜訊，不會改變任何認真評估的人對兩家模型的判斷。真正有意義的是 DeepSeek 複製了 Anthropic「模型加 Claude Code」的捆綁打法，把模型調校成在自家 harness 與騰訊工具裡表現最好，一旦 tool schema 針對 V4.1 硬優化，其他模型插入同一 harness 就有結構性劣勢且短期不可逆。這場仗和同週 Replit 換掉 Claude 預設是同一場仗：模型商品化之後，勝負落在誰掌握 harness 與預設路徑。

值得追問
  1. DeepSeek Harness 8 天拿 197k GitHub stars，但 dsh 的週活開發者、平均 session 長度、實際跑完一個完整 task 的 completion rate，跟 Claude Code 比是什麼量級？有沒有任何第三方數據？
  2. DeepSeek 綁騰訊 WorkBuddy 拿到的是真正的預設位，還是只是選單上的一個選項？如果 system prompt 層的 tool schema 綁定了 DeepSeek，其他模型在同一 harness 裡的劣勢是不可逆的嗎？

Google Willow 論文把量子攻擊的距離尺給出來了，但比特幣真正的問題是治理

事實背景

Google 團隊在 Science 發表論文，在 Willow 量子處理器上用「cultivation」方法製備 magic state，錯誤率降低約 40 倍，通過檢查的 state 保真度約 99.99%，但只有約 8% 的嘗試通過。CoinDesk 指出，模型化攻擊需要在公鑰曝光後約 9 分鐘內每秒產出約 500,000 個可靠 magic state。Google 3 月估計，不到 500,000 個實體 qubit 的超導量子電腦即可破解 Bitcoin 與 Ethereum 的錢包密碼學。近期有老幣異動：10-07 一筆自 2010 年 7 月未動的 100.02 BTC（約 $850 萬）移動；8 月 6 個 2011 至 2014 年休眠錢包移動 553.59 BTC（當時約 $4,000 萬）。Shor 演算法 1994 年發表，至今尚未有人實際以量子電腦示範破解。

So What?

這個結果真正的意義是把攻擊門檻的瓶頸具體化了：不是「有沒有夠多 qubit」，而是「每秒能不能產出 50 萬個可靠 magic state」，8% 的良率就是那個距離的刻度。但比特幣面對的最大問題不在密碼學，而在治理：P2PK（Pay-to-Public-Key，公鑰直接寫在鏈上的早期比特幣輸出格式）幣的持有人若不存在，就沒有人能把它們搬到抗量子地址，社群凍結這些幣需要軟分叉且政治共識極難達成，持有現貨 ETF 的被動投資者承受的是一個沒有人在定價的尾部風險。

值得追問
  1. 如果 Satoshi 的約 110 萬枚 P2PK 比特幣永遠無法遷移到抗量子地址，社群凍結它們等於憑空蒸發近千億市值，哪家持有 BTC 現貨 ETF 的資管公司已經在 NAV 模型裡對這個尾部風險定價？
  2. 比特幣社群裡真正會因為這篇 Science 論文而採取行動的客戶是誰？交易所、託管商、還是礦池？他們現在有沒有人已經在為抗量子遷移付費，還是這整件事停在「重要但不緊急」所以根本沒有 GTM？

Circle 把 CCTP 高速公路開放給外人，是因為 float 這條收入曲線快撐不住了

! Circle 的 CCTP 轉型揭示了高利率環境下穩定幣發行商的估值地雷。
事實背景

Circle 共同創辦人兼 CEO Jeremy Allaire 在 a16z crypto 播客訪談中宣布，在 Arc 上發行的資產（包括代幣化股票、其他穩定幣、代幣化信貸）皆可使用 CCTP，打破過去 CCTP 只供 USDC 使用的限制。USDC Q2 末流通量 $733 億，Circle 每季 mint 與 redeem 約 $1,500 億。Arc 主網於 9 月 16 日上線，創始驗證者包括 BlackRock、DTCC、Visa、Mastercard 等約 11 家機構，目前為 proof-of-authority，規劃 2027 年轉 proof-of-stake。同週 BIS Working Paper No. 1382 顯示，銀行平均存款利率單週升 1bp，穩定幣市值 10 週平均成長率從約 15% 降至作者偏好估計的約 6%，且 USDC 的反應強於 USDT，作者歸因於 USDC 與美國用戶連結較深。Circle 2026 年 5 月以 $9,650 億估值募資 $650 億。

So What?

BIS 的實證直接打中 Circle 的估值邏輯核心：USDC 對銀行存款利率的敏感度比 USDT 高，若聯準會 2027 年不降息，靠 float 撐起 $9,650 億估值隱含的營收倍數會很困難。把 CCTP 開放給第三方資產，是 Circle 試圖從穩定幣發行商轉型成跨鏈基礎設施收費商的明確訊號。問題是這條「過路費」的實際 take rate 與交易量完全未披露，第二曲線能否補上 float 壓縮，現在無法估算。

值得追問
  1. BIS 數據說銀行升息 1bp 就能把 USDC 成長率砍掉大半而 USDT 幾乎不受影響，Circle 把 CCTP 開放給第三方資產，本質上是在承認 float 收入靠不住、要靠跨鏈過路費建第二曲線，那這條過路費的實際 take rate 跟交易量現在是多少？
  2. Arc 驗證者名單上掛了 BlackRock、DTCC、Visa 這些大名字，但 proof-of-authority 階段這些機構到底有沒有在跑真實交易量，還是只掛個節點站台？如果 Mastercard 或 Visa 明天自己做一條許可鏈跑 CCTP 的競品，Circle 能防守的到底是什麼？
