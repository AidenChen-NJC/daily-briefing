Anthropic IPO 的真正壓力測試不是估值，是那 $47B 裡有多少是「自己人的錢」

事實背景

Anthropic 於 6 月 1 日向 SEC 機密遞交 Form S-1（美股 IPO 前的招股說明書草案，「機密遞交」代表財務數字暫不公開），正式啟動 IPO 程序，成為第一家叩關公開市場的前沿 AI 公司。此時估值 $965B，剛完成的 Series H（第 8 輪私募）募資 $65B，年化營收 run rate（當月營收乘以 12 的估算口徑）達 $47B，比去年全年 $10B 暴增。競爭對手 OpenAI 私募估值 $730B，傳最快今年 9 月跟進遞件。

So What?

研究指向一個關鍵問題：Anthropic 的 $47B run rate 裡，Amazon 承諾投入 $40B、Google 注資超 $3B，兩者同時也是其最大雲端客戶。若這些關係人合約被計入營收，剝除後真正來自市場的收入恐怕不到一半。公開市場分析師參考 Snowflake、Palantir 的 IPO 先例，會直接要求拆分客戶集中度與關係人收入，屆時支撐 $965B 的倍數就失去基礎。這不只是 Anthropic 自己的賭局，一旦公開市場定價打折，Lightspeed 和 Spark Capital 的 LP 將被迫重新標記整個 AI portfolio，觸發一輪帳面估值的連鎖下修。

值得追問
  1. Anthropic 搶先遞 S-1 的 GTM 邏輯是：如果 OpenAI 先上市並鎖定「財務透明的預設選擇」定位，大型企業採購會優先往已上市供應商靠，Anthropic 會不會就此永遠扮演高價替代方案？
  2. 如果 IPO 定價比 $965B 低兩成，Series H 的 Iconiq、GIC、安大略教師退休基金的帳面收益蒸發，哪家 LP 會第一個被迫重新標記整個 AI portfolio？

微軟自研模型的真正目的不是打敗 Anthropic，而是讓 OpenAI 的 $730B 失去地基

事實背景

微軟於 Build 開發者大會發表 MAI-Code-1-Flash，是其首款 AI 編碼模型，能把文字描述轉成原始碼，主打「推論（inference，模型生成輸出的運算過程）超高效率」，已整合進 GitHub Copilot 與 Visual Studio Code。MAI 部門由 Google DeepMind 共同創辦人 Mustafa Suleyman 領軍，2024 年 3 月設立。GitHub Copilot 目前有 150 萬付費用戶。

So What?

研究給出高信心的判斷：IDE（整合開發環境）的預設位置才是真正的護城河，而非模型技術本身。微軟把 MAI-Code-1-Flash 設為 Copilot 預設模型，等同於用通路封殺垂直 coding agent 新創，因為開發者習慣是在 IDE 內按 Tab 接受建議，切換供應商的摩擦極高。Cursor、Codeium 等 IDE-native coding agent 新創是短期明確的輸家，微軟的 GitHub Enterprise 企業合約戶是贏家。更深一層，若 MAI 成功替代 GitHub Copilot 內的 OpenAI 推論流量，OpenAI「微軟是最大穩定單一客戶」的核心敘事將鬆動，其 $730B 私募估值的收入基礎將失去最重要的分銷背書。

值得追問
  1. IDE 內的預設位置是不是唯一真正的護城河？如果有人做垂直領域的 coding agent 直接賣給企業，模型本身誰都能換，但微軟的通路壟斷能繞過去嗎？
  2. 微軟現在同時維護 OpenAI 和 MAI 兩套推論管線，省下的 token 成本會不會被雙軌的工程複雜度吃回去？

Alphabet 用稀釋股東來建 AI 算力，是在告訴市場這筆 capex 遠比公開數字大

事實背景

Alphabet 於 6 月 1 日宣布計畫賣出 $80B 股票（stock sale，賣股募資，會稀釋現有股東但不增加負債），其中含 Berkshire Hathaway 投資 $10B。募資用途指向「世界級 AI 算力基礎設施，以滿足前所未有的客戶需求」。巴菲特旗下 Berkshire 罕見大手筆參與科技公司增資。

So What?

Alphabet 2025 年自由現金流約 $72B，在這個規模下仍選擇稀釋股東而非動用現金，研究的中信心判斷是：AI capex 的實際承諾金額（含長期資料中心建設合約）遠超過公開的年度數字，稀釋股東是在告訴市場「這是複數年的剛性承諾，不是單年支出」。這對 AWS 構成壓力，對 Azure 則是同步訊號，兩者都在以超出單一年度現金流的速度押注算力。結構性最脆弱的反而是 Alphabet 自身，因為 TPU（Google 自研 AI 晶片）是封閉生態，若未來模型架構迭代不適配 TPU 的矩陣運算優化，這 $80B 的邊際效率將比 Nvidia GPU 叢集更快遞減。

值得追問
  1. $80B 建的資料中心要三到五年才上線，模型架構迭代週期已壓縮到 12-18 個月，在基礎設施彈性上誰有結構性優勢來避免「建好即過時」？
  2. Google Cloud 的 AI 算力產能利用率到底是多少？$80B 砸下去，是已經有客戶排隊等不到機器，還是先蓋了再靠降價搶 AWS 和 Azure 的存量客戶？

Nvidia 喊的 $200B CPU 市場是混淆視聽，它真正能碰到的增量只有 $10-20B

事實背景

Nvidia 於 Build 大會發表 RTX Spark，是其面向 Windows 筆電的 AI 整合晶片，與台灣聯發科（MediaTek）合作，年內將在 Microsoft、Dell、HP、ASUS、Lenovo、MSI 等品牌的新一代 PC 首發。黃仁勳演示「24/7 不間斷運行、無計費焦慮」的 agent PC（內建可常駐執行任務的 AI agent 個人電腦），並稱 Nvidia 正在進軍 $200B CPU 市場。

So What?

研究給出高信心判斷：$200B 是整個 PC CPU 市場含 x86 存量，但 RTX Spark 採 Arm 架構，Windows-on-Arm 目前市佔低於 5%，且大量 legacy 企業軟體仍不相容。這個 TAM（可觸及市場總規模）數字是刻意的「narrative math」，真正可切的增量是「新購 AI PC」細分，規模在 $10-20B 量級。Intel 和 AMD 的存量市場不會因此動搖，真正受壓縮的是它們在 AI PC 增量細分的定價權。Nvidia 的真實戰略意圖不是靠這顆晶片賺硬體利潤，而是把 CUDA 生態延伸到 PC 端，鎖住未來的 agent 開發者，這是平台博弈，不是硬體毛利博弈。

值得追問
  1. 黃仁勳喊的「24/7 agent PC、無計費焦慮」，實際上有哪個 agent 用例是消費者願意讓它常駐本地不間斷跑的？還是這只是把雲端推論成本轉嫁成硬體售價的包裝話術？
  2. Intel 和 AMD 在 OEM 通路的真正防禦是二十年的主機板生態與採購關係，Nvidia 靠聯發科繞過 x86，OEM 願意為了 GPU 品牌溢價承擔切換整條供應鏈的風險嗎？

比特幣跌破 $60,000 的關鍵不是散戶恐慌，而是「最大買家」可能變成被迫賣方

事實背景

比特幣於 6 月 5 日跌破 $60,000，盤中低見 $59,764.90，為 2024 年 10 月以來最低；當日上午報 $61,928.70。BTC 本週跌約 17%，較歷史高點低約 50%。美國現貨比特幣 ETF（exchange-traded fund，在證交所交易的基金）本週淨流出約 $10 億美元，淨資產從 5 月 14 日的 $107.8B 降至 $80.4B。6 月 4 日約 $15 億美元加密多單遭強平（long liquidation，槓桿做多者被強制平倉），24 小時內逾 $3.86 億美元以太坊倉位遭清算。Strategy（前 MicroStrategy，全球最大企業 BTC 持有者）傳出轉由買方變賣方。

So What?

研究中信心指出：Strategy 的帳面持倉成本約 $67,000-$68,000，目前價格已在成本線下方，其可轉債持有人（到期日集中在 2027-2029 年）若股價持續低迷將面臨還款壓力，Saylor 可能被迫賣 BTC 以維持可轉債服務。這不是主動策略轉向，而是可轉債結構驅動的強制路徑。更深的問題是：過去兩年「機構永久持有 BTC」的敘事，本質上一直是 Strategy 一家公司的槓桿操作在撐，真正長期配置型的邊際買盤從未如敘事所描述的那樣存在。

值得追問
  1. Strategy 如果真的從買方變賣方，那過去兩年所有「機構採用 BTC」敘事的底層牽引力，是不是從頭到尾都是一家公司的槓桿操作在撐？
  2. ETF 資金明確輪動到 AI 股和黃金，如果現在要做一個 crypto 產品的 GTM（市場推廣），真正的邊際買盤到底在哪裡，散戶、RIA（理財顧問）還是主權基金，誰還沒跑？

Ramp 估值半年跳 37%：Iconiq 和 GIC 付的溢價，超過六成是在為「AI」兩個字買單

事實背景

據 Crunchbase 統計，6 月 5 日當週最大募資為企業支出管理平台 Ramp 的 $750M，由 Iconiq、GIC、安大略教師退休基金領投，投後估值（post-money valuation，投前估值加本輪募資額）來到 $44B，六個月前為 $32B，更早為 $22.5B。同週三筆大輪：Flourish（仿人腦 AI）募 $500M，投資人含 Jeff Bezos、Lux Capital、Google Ventures；核融合新創 Helion 募 Series G $465M，投後估值 $15.5B，Thrive Capital 領投；NewLimit（表觀遺傳重編程，指不改 DNA 序列而重設基因開關讓老細胞恢復年輕功能的抗老技術）募 Series C $435M，Founders Fund 領投，由 Coinbase CEO Brian Armstrong 共同創辦。

So What?

研究中信心判斷：Ramp 核心業務（企業信用卡返點與支出管理）的市場規模和競爭格局並未改變，Brex 與 Expensify 的壓力也沒消失，合理估計這次 37% 溢價裡超過 60% 是在為「AI 支出自動化」的敘事買單，而非可驗證的 NRR（淨收入留存率，衡量現有客戶擴約意願的指標）提升。這與 2021 年 fintech 泡沫的結構高度相似，當時的標籤是「嵌入式金融」，現在換成 AI。若 Ramp 在 IPO 前無法展示 AI 功能帶來的可量化客戶擴張，這個估值將成為下一個 Klarna 式的公開市場重估對象。

值得追問
  1. Ramp 的 AI 功能到底帶來多少增量 NRR？客戶是因為 AI 自動化支出審批才擴約，還是只是銷售簡報多了幾頁 AI slides？
  2. NewLimit 拿 $435M 做表觀遺傳重編程，Founders Fund 給這個 pre-revenue 生技公司的隱含估值是多少，跟同賽道已有臨床數據的 Altos Labs 相比是溢價還是折價？
