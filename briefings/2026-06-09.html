政府持股 OpenAI，真正的輸家是 Anthropic 和 xAI

事實背景

OpenAI 是目前估值約 $3,000 億的非營利轉型 AI 公司，Sam Altman 早在 2025 年即向川普政府提議讓政府取得股權。白宮正與 OpenAI 商議將 1–5% 股份注入一檔「公共財富基金（Public Wealth Fund）」，讓美國人分享 AI 收益。參議員 Bernie Sanders 提出的版本更激進，主張對最大型 AI 公司課徵一次性 50% 股票稅，以股份（非現金）支付並存入公共基金，賦予一般美國人投票權與董事會席次。川普上週五公開稱此構想「幾乎是與美國公眾的合夥關係」。前美國 AI 沙皇 David Sacks 反對，稱此舉會加速政企融合。談判實際上已進行逾一年。

So What?

政府一旦持有 OpenAI 股份，任何對 OpenAI 不利的反壟斷裁決都會直接損害政府資產淨值，聯邦採購競標對 Anthropic 和 xAI 的隱性傾斜幾乎無法被審計到。這才是真正的問題所在，不是「分紅數學夠不夠漂亮」。1–5% 股權按 $3,000 億估值約值 $30 億至 $150 億，分給三億美國人每人一次性 $10–$50，在 OpenAI 轉虧為盈前川普「讓他們變有錢」的說法是純政治修辭。

值得追問
  1. 如果政府同時是股東與監管者，Anthropic 和 xAI 在聯邦採購競標中會被結構性排擠，它們現在能做什麼防禦動作，還是已經來不及了？
  2. 美國政府同時成為 OpenAI、Anthropic、xAI 的股東與監管者，未來任何反壟斷裁決都直接影響自己的資產淨值，哪個 LP 敢在這種結構下繼續對這三家做 late-stage 定價？

OpenAI 的超級應用轉型，正在幫 Anthropic 在企業端築牆

事實背景

OpenAI 計劃在「未來數週」推出迄今最大規模的 ChatGPT 改版，將其重建為整合 ChatGPT、瀏覽器與 Codex（代理式編程平台，AI 自主執行多步驟開發任務）的超級應用（superapp，單一介面整合多功能）。Codex 自 2 月推出以來週活躍用戶成長 6 倍，達 500 萬以上。ChatGPT 用戶數接近十億。一名資深 OpenAI 員工告訴 Financial Times「Chat is dead」。策略是將免費用戶導向 Codex 等付費產品，在 IPO 前衝刺獲利。

So What?

Claude Code 靠終端原生整合嵌入企業 CI/CD 工作流（持續整合與部署流程），切換成本是整個工程流程重組，不是換一個 app。OpenAI 把 Codex 包進 web 容器的超級應用反而在個人用戶端有導流效果，但在企業側等於主動強化了 Anthropic 的留存護城河。研究指向一個結論：這次改版的輸家是 OpenAI 企業端，短期贏家是 Anthropic 的企業黏性。

值得追問
  1. Codex 週活 500 萬裡多少是把它當免費 debug 工具用完就走的？相比 Claude Code 已經嵌進企業 CI/CD 工作流，Codex 的 7 日留存和付費轉換率到底是多少？
  2. Anthropic 的 Claude Code 靠終端原生整合拿下開發者工作流，OpenAI 把 Codex 塞進超級應用的 web 容器反而多了一層抽象，這是結構性劣勢還是他們有繞過的方案？

Amazon 的「淨增就業」算術，是每年 $2.9B 的成本套利包裝

! Amazon「淨增就業」的數字掩蓋了一個每年 $2.9B 的人力套利，這才是 €100 億投資的真實 IRR 來源。
事實背景

Amazon 在倫敦「Delivering the Future」活動發表新一代 Proteus 自主移動機器人（AMR，autonomous mobile robot），工人可用純口語指令直接下令，無需技術培訓或編程介面，機器人即能在倉庫導航、搬運重型推車並排定任務優先序。同步宣布投入 €100 億（約 $116 億）現代化歐洲履約（出貨倉儲作業）設施，新版 Proteus 預計 2027 年上半年起在歐洲部署。此次發表正撞上 Amazon 白領裁員，10 月一輪裁 1.4 萬人、累計約 3 萬人。Amazon 承諾此筆支出將新增 2.5 萬個歐洲物流職缺，並擴大一項 $10 億的勞工培訓計畫。Amazon 現有超過 100 萬台機器人，逼近其 156 萬名員工，機器人支撐 75% 的配送。

So What?

3 萬白領年薪保守估 $120K，年省人力成本約 $36 億。新增 2.5 萬歐洲倉儲崗均薪約 €25K，年新增成本約 €6.25 億（約 $7.25 億）。淨年化節省約 $29 億，€100 億投資的 IRR 在 4–5 年回收期內可能超過 25%。「淨增就業」的說法是包裝，這才是 Proteus 發布會背後的真實財務邏輯。

值得追問
  1. Amazon 承諾的 2.5 萬個歐洲物流職缺，有多少是 Proteus 部署完成後就會被自動化掉的過渡期崗位？
  2. 口語指令介面的真正 GTM 目的是降低培訓成本、讓現場工人更快被替換成更便宜的工人，那 Agility 或 Figure 的通用人形機器人什麼時候會讓 Proteus 這種專用 AMR 變成過渡方案？

Bezos 投 Generalist AI 不是對沖 Amazon，是幫 Amazon 提前卡位供應商

事實背景

機器人新創 Generalist AI 完成 $4 億募資，投後估值（含本輪資金）達 $20 億，由 Radical Ventures（專注 AI 的創投）領投，8VC、Union Square Ventures、Norwest、Hanabi Capital 參與，既有投資人 Nvidia 與 Bezos Expeditions（Jeff Bezos 個人投資基金）跟投。公司主打 GEN-1 具身機器人基礎模型（embodied robotics foundation model，把大模型接上實體機器人軀體以學習空間與動作），用以讓機器人處理日益複雜的任務。

So What?

這不是 Bezos 在對沖 Amazon 的內部機器人路線。Amazon 自建 Proteus 控制倉儲應用層，Bezos 個人押注通用具身基礎模型層，這是「平台層對應用層」的雙押，目的是讓 Amazon 成為 GEN-1 最大客戶而非競爭者，同時讓 Bezos 個人享有財務上漲空間。真正的風險承擔者是 Generalist AI 其他股東，因為若 Amazon 採購談判時利用股東身份壓價，他們沒有任何制衡手段。

值得追問
  1. Bezos Expeditions 投了你、Amazon 自己有百萬台機器人和內部 AI 團隊，如果 Amazon 不是付費客戶而只是股東，這個背書除了 PR 之外對客戶獲取通路到底有什麼實質幫助？
  2. GEN-1 如果明天被拿去跑 Amazon 以外的工業場景，最難被複製的到底是模型本身還是訓練數據的獨佔來源？

歐洲 robotaxi 元年，Uber 是唯一不用燒錢的贏家

事實背景

全球私人 robotaxi（無人駕駛計程車）車隊去年翻倍至約 8,000 台，橫跨 20 個以上主要城市。2035 年全球 robotaxi 數量預測落在 70 萬至 600 萬台之間，差距近 10 倍。歐盟推出新的跨境「test bed」框架（允許企業在受控條件下跨境試營運）以加速審批。歐洲首個商業化形式試運營於 4 月在 Zagreb 啟動，Pony.ai 運營約 10 台 robotaxi。2026 年進駐計畫：Waymo 在倫敦部署約 100 台全電動 Jaguar I-Pace，配人類安全員（safety operator）；Uber 同時接入 Waymo、Wayve、Baidu Apollo Go（倫敦）、WeRide（馬德里）、Momenta（慕尼黑）。倫敦、馬德里付費服務最快 2027 年到位。

So What?

Uber 同時接入 Waymo、Baidu、Momenta、Wayve，這是平台策略而非技術押注。每台車含安全員的當前運營成本大概率高於 Uber 司機，等於由三家車隊補貼歐洲市場教育，Uber 坐收平台佣金、零成本等待每英里成本燒到低於有人駕駛再獨家談判。至於 Zagreb 的 Pony.ai 10 台車，10 台根本達不到任何 robotaxi 調度密度模型的盈虧平衡門檻，「歐洲首個商業化試運營」的標籤目的是卡位監管敘事、支撐下一輪融資，不是真的在驗證商業模式。

值得追問
  1. Pony.ai 在 Zagreb 放 10 台車就叫「歐洲首個商業化試運營」，這是真的有付費乘客和正單位經濟，還是純粹搶一個監管先行者的敘事位置來拿下一輪融資？
  2. Wayve 夾在 Waymo 的規模和中國車隊的成本優勢之間，它唯一的防禦是「歐洲本土牌」，但歐盟 test bed 框架明確允許跨境，這張牌還剩多少價值？
