小鵬的機器人王牌不是 IRON，是它管了幾十萬台車的那套營運系統

事實背景

小鵬（XPeng）是在紐約與香港兩地上市的中國電動車廠。它 11-25 在廣州 AI Day 發表新版 IRON 人形機器人，規格是 76 個自由度（DoF，機器人可獨立轉動的關節數，越多動作越靈活）、1,500 個以上觸覺感測點，以及 3 顆自研 Turing AI 晶片。時程是 2027 年 1 月量產，第一季先在自家門市當銷售助理，第二季公開發售。聯席總裁 Brian Gu 說售價約等於小鵬電動車的中位價格，媒體換算約 $18,000 至 $46,500，正式價格未公布。IRON 和 2027 年要上路的 YOYO-01 robotaxi（無人駕駛計程車）共用 VLA 3.0 架構（Vision-Language-Action，把視覺、語言理解與動作控制放在同一個模型）。Counterpoint 統計 2026 上半年全球人形機器人出貨逾 22,000 台，AgiBot 約 9,700 台居首，Unitree 約 7,000 台第二，但六成以上用在表演與研究。小鵬股價今年跌逾 55%，AI Day 當天續跌。

So What?

研究指向一個反直覺的結論：在「能實際營運的商用機器人」這一塊，小鵬比出貨量冠軍 AgiBot、Unitree 更接近 Tesla 的打法，因為它手上已經有數十萬台車的 OTA（空中軟體更新）、遠端診斷與資料回流系統，而 Unitree 的研究客戶多半自己寫控制軟體，原廠從來不用管車隊營運。換句話說，「賣硬體給研究機構」這個讓 Unitree 衝上出貨前段班的模式，一進入服務市場反而會吃虧。這個判斷信心中等，車用能力能不能移植到機器人還沒有公開證據，2027 Q1 門市部署時小鵬會不會公布遠端接管比例與 OTA 頻率，是第一個檢驗點。

值得追問
  1. AgiBot 和 Unitree 合吃七成市佔，可是出貨六成是表演和研究，有沒有哪個企業客戶第二年回頭買了第二批？還是全球這兩萬多台，其實都是一次性的展示採購？
  2. 小鵬先讓 IRON 在自家門市上班，跟 Tesla 把 Optimus 塞進自己工廠是同一招。那第二季開賣時，第一個外部付費通路會是誰，經銷商、系統整合商還是直營電商？小鵬又拿什麼讓他們願意壓庫存？

Google 的 agent 新規打中的不是 LangChain，是替你回信的 email 新創

! Google 用條款和價格把「AI 軟體」單獨分類，這是第一個大型平台公開劃線，決定哪些 agent 能替使用者動手。
事實背景

Google 11-25 宣布 Workspace MCP 伺服器正式上線（MCP 是 Model Context Protocol，讓 AI 模型呼叫外部工具與資料的開放標準），涵蓋 Gmail、Drive、Calendar 等 8 個產品。新條款規定，2027-02-01 起所有 AI agent 都得透過 MCP 或 CLI 存取 Workspace。繼續直接呼叫 REST API（一般 app 讀寫 Gmail 用的傳統程式介面）的 agent，不管付多少錢，一律只給免費 Standard 級配額。免費級是每專案、每產品每天 5,000 次 MCP 請求，Gmail 搜尋一次算 10 次。付費級 2027-04-01 起計費，價格未公布。公開版 Gmail MCP 可以搜尋、讀信、建草稿，但不能寄信、回信或轉寄，Google 稱這些工具「需要 partner access」，沒有說明誰算合作夥伴。Google 給的理由是 agent 在機器速度下容易被 prompt injection（在信件或網頁裡埋指令，誘使 AI 做使用者沒授權的事）操控。

So What?

研究點出一個標題沒說的輸家：受傷最重的不是 LangChain、CrewAI 這類框架，它們只是程式庫，本身不持有 OAuth client（app 向 Google 申請存取使用者資料的身分憑證），真正結構性出局的是 Shortwave、Fyxer、Lindy 這類核心功能就是代寫、代回信的垂直 email agent。公開版 MCP 只能建草稿，等於直接拔掉這些產品的主功能。贏家是 Gmail 內建的 Gemini，以及拿得到 partner tier 的大廠，這個判斷信心中等，因為 Gmail 工具限制來自二手引述的 Google 文件。

值得追問
  1. Anthropic 的 Claude connector 標榜能寄信，獨立開發者卻只能建草稿。Google 這個「partner access」背後真正換的是什麼？分潤、資料回流，還是一紙不做 Workspace 競品的承諾？
  2. MCP 閘道在每個請求上插 DLP（資料外洩防護）掃描和使用者確認，一個要連續操作 Gmail 的 agent 可能一次任務就卡十幾次。哪些 agent 的工作流程，在這種延遲下根本跑不起來？

Tether 抽兩成也丟不了交易所，該擔心的是只聽法院的 Circle

事實背景

Tether 是市值最大的美元穩定幣 USDT 的發行商。Bloomberg 11-24 調查指出，Tether 對部分駭客受害者索取最高 20% 的重新發行費（reissue，把凍結的幣作廢、再發同額新幣給原主），才肯歸還被凍結（發行商在智能合約層鎖住特定地址的穩定幣）的 USDT。新加坡交易所 Bittok 2020 年 6 月被駭 $50M，五年多後仍未拿回。Tether 自家公開的誤轉回收費上限是回收金額 10% 或 $1,000 取高者，對駭客案則沒有公開費率或時限。USDC 發行商 Circle 走另一條路，只聽法院命令。美國司法部 11-23 對 Binance 被盜的逾 $1.1B USDC 提起民事沒收（civil forfeiture，政府對涉案財產本身提告，不需起訴個人）。Circle 4 月在 Drift Protocol 被盜案中等法院命令，讓約 $232M USDC 八小時內被轉走，現在遭逾 100 名投資人起訴。

So What?

研究指向一個反直覺的結論：Tether 抽 20% 幾乎不會讓它失去交易所，因為大型交易所挑穩定幣看的是流動性和交易對深度，不是被駭後的回收條款，PayPal 的 PYUSD、Ripple 的 RLUSD 主打合規透明，到今天也沒撼動 Tether。任何打「凍結免費、回收透明」牌的新發行商，都會掉進 Circle 的兩難，凍太快要承擔誤凍訴訟，凍太慢就是下一個 Drift。真正的風險在 Circle，一旦 Drift 訴訟形成對它不利的判例，「只聽法院」就從護身符變成負債，不過判決方向未知，這個判斷信心中等。

值得追問
  1. Circle 自家的 CCTP 跨鏈橋，理論上可以在驗證層加一道即時黑名單檢查。Drift 那 $232M 八小時就被搬走，Circle 沒做這件事，是架構上做不到，還是刻意不做？這個選擇又讓誰撿到了套利空間？
  2. Binance 正在跟 Tether 私下談那 $1.5B 怎麼還。如果 Tether 對 Binance 也報 20%，就是 $300M，這筆錢最後是誰吞下去，Binance 的股東，還是用戶的保險基金？
