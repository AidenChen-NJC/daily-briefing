OpenAI 買到的不只是程式碼儲存，而是 Lovable、Bolt、Amp 的遷移談判籌碼

事實背景

Meta 11-04 確認收購 AI coding 新創 Conductor，同日 Axios 報導 OpenAI 計畫收購 Pierre Computer，將其 Code Storage 技術整合進旗下 coding agent（寫程式的 AI 代理）Codex。Conductor 成立不到兩年，核心產品去年夏天上線，雲端服務 11-20 關閉，用戶僅有 16 天搬走資料。Pierre 的開源函式庫 Trees 與 Diffs 已在 Codex 內運作；Pierre 官網列出的客戶包括 Lovable、Bolt、Amp，均是 Codex 的直接競品。兩筆交易金額均未揭露。

So What?

Pierre 技術裡的 32TB 單庫上限與 30 個以上併發寫入最佳化，幾乎肯定含有私有路徑，開源層替代不了。Lovable 和 Bolt 交易完成後，程式碼儲存供應商就是競爭對手，遷移成本高，是人質而非自願客戶。真正的贏家是 OpenAI：即便競品最終遷出，遷移期間的程式碼讀寫資料對訓練仍有殘餘價值。

值得追問
  1. Pierre 的客戶名單裡 Lovable、Bolt、Amp 這些公司，交易消息出來後有任何一家開始搬遷 Code Storage，還是他們根本沒有替代方案所以只能留下來餵養競爭對手？
  2. Pando 自建 Git 後端（程式碼版本庫的儲存系統）與 Pierre Code Storage 都處理併發寫入，合併時 conflict resolution 層由誰決定，還是會變成兩套並存的技術債？

借錢蓋資料中心的跌 9–21%，「現有資產更值錢」是真實的定價邏輯

事實背景

民主黨 11-04 贏得美國參眾兩院，並在資料中心重鎮德州與喬治亞州勝選。當日資料中心營運商重挫：Cipher Digital 跌 21%、CoreWeave 跌 9.5%、Applied Digital 跌 8.8%，電力股 Vistra 跌 15.4%。反方向，Amazon 漲 6%、Microsoft 漲 6%、Alphabet 漲 4.6%。Dow 單日漲逾 1,500 點（+3%），為 2025 年 4 月以來最佳單日。分析師 Art Hogan 直言建設放緩讓「現有資產更值錢」，Mark Malek 則說最脆弱的是借錢的一方。

So What?

現有容量的 hyperscaler（超大規模雲端業者）可以調高 GPU 租賃定價或用長約鎖定客戶，把 CoreWeave 的潛在客戶提前吃掉，這對 CoreWeave 的再融資才是真正的威脅，不是監管本身。CoreWeave 的收入高度集中於 Microsoft，一旦 Microsoft 自給率上升，收入集中風險與債務槓桿同時曝光。電網互聯排隊已是 3 至 5 年，電力審批失敗才是讓已動工設施無法上線的卡點，土地許可只是推遲動工，兩者影響截然不同，但 Hinojosa 政策細節尚未確認。

值得追問
  1. CoreWeave 等 neocloud 的債務契約裡，如果州級電力許可延遲導致資料中心無法如期上線，觸發交叉違約的門檻到底有多窄？
  2. CoreWeave 這些 neocloud 的客戶合約鎖定期和提前終止條款長什麼樣。如果建設放緩讓交付延遲，客戶是付違約金走人還是被綁死等機房蓋好？

Qualcomm 的 $5B 資料中心目標，定價的是 HBM 供應商的出貨時程，不是需求

事實背景

Qualcomm 公布 FY26 Q4 財報，non-GAAP（排除股權薪酬等項目的調整後財務數字）營收 $10.442B，年減 7%；手機晶片（QCT）$5.137B，年減 26%，低於預期 $5.21B；汽車 $1.990B，年增 89%，高於預期。資料中心季營收 $650M，FY27 目標 $5B。Q1 FY27 指引營收 $10.4 至 $11.2B，non-GAAP EPS $2.15 至 $2.35。盤後跌約 6.5 至 7%。CEO Cristiano Amon 稱資料中心「不是需求問題，是供給問題」。

So What?

從 $650M 到 $5B 年化，每季需要接近 50% 的環比成長，但 Amon 自己說瓶頸是供給而非需求。這個目標實質上是對 HBM 與先進封裝供應商（三星、SK Hynix、TSMC CoWoS）交貨時程的押注，不是 Qualcomm 的銷售能力。若 HBM 優先供給 Nvidia，Qualcomm 的資料中心線無論需求多強都無法達標，這個目標的可信度完全外包給供應鏈。

值得追問
  1. 資料中心季營收 $650M 要在 FY27 衝到 $5B 年化，現有 design win 的客戶除了 Amazon 之外到底還有誰在量產拉貨，還是這個數字靠的是尚未簽約的 pipeline？
  2. 資料中心季營收 $650M 要在兩年內跑到 $5B 年化，Qualcomm 的自研 Oryon 核心在推論工作負載上缺什麼具體的軟體生態才讓客戶不敢下單？

法官讓股票永續繼續交易，同時預告 Kalshi 很可能在開違法的倉

! 法官在同一份裁定裡拒絕叫停交易，又明言原告「很可能在實體上勝訴」。Kalshi 目前在法律預告可能違法的狀態下持續運營，這是本週監管風險最高的單一事件。
事實背景

CFTC 主席 Michael Selig 11-03 宣布開放美國股票永續合約（perpetual futures，無到期日的衍生品）交易，將其歸類為 security future（證券期貨），由 CFTC 與 SEC 共管。Capital Markets Alliance 當天提告，主張此類產品應歸 SEC 管轄的 security-based swap（證券型交換合約）。法官 Valerie Caproni 拒絕發暫時限制令（TRO），理由是原告無法證明立即且不可回復的損害，但她同時認定原告「很可能在實體上勝訴」。Kalshi 11-04 已上架 Qualcomm、McDonald's、Amgen、Costco 四檔，最高槓桿 4.9 倍。

So What?

TRO 失敗的唯一原因是損害舉證不足，不是實體法律爭議。法官明確認為永續合約依定義不含「單一證券的未來交割」，因此不可能是 CFTC 有權管的 security future，更像 security-based swap。若最終裁定如此，零售投資人本不能持倉，Kalshi 面臨的不只是產品下架，而是已開倉部位的合規責任，誰來承擔損失目前無答案。

值得追問
  1. Kalshi 上架第一天那四檔股票永續的實際成交量和未平倉量是多少。如果法院最終判 CFTC 越權，已開倉的用戶怎麼被清算，Kalshi 有沒有準備好這個情境？
  2. Cboe 的 Craig Donohue 站在原告那邊告 CFTC，ICE 卻押注 trade.xyz 走相反方向。這兩家傳統交易所的股東該怎麼理解同一個產品類別裡自家管理層的對賭？
CoinDesk、CNBC、Bitcoin Magazine Web3

花 $125.5M 押共和黨，買到的是民主黨擁有更大動機寫出懲罰性法案

事實背景

CLARITY Act（美國加密市場結構法案）今年 9 月在參院程序投票以 49 對 50 未過，本屆國會 2027-01-03 結束後自動失效。加密 PAC（政治行動委員會）本次選舉支出約 $170.5M，至少 $125.5M 流向共和黨。民主黨橫掃後，眾院民主黨正討論新版法案，擴大 SEC 角色、縮小 CFTC 角色，並加入針對 Trump 的道德規範條款，文本尚未公布。BTC 當日一度跌破 $76,000，下午回升逾 $80,000，約漲 3%。

So What?

業界把 $125.5M 押共和黨，結果讓民主黨有充分動機把下一版法案寫成懲罰性條款。Ruben Gallego 直言「那已是他們能拿到最好的法案」，代表加密業界的談判槓桿已用盡。更值得注意的是，同一週立法路線（CLARITY 死亡）與行政路線（CFTC 開放股票永續被法官質疑越權）同時受阻，業界剩下的合法擴張通道只剩 OCC（美國貨幣監理署）規則與州級牌照，兩者均無法覆蓋交易市場結構。

值得追問
  1. BTC 在法案前景惡化當天反彈破 $80K，Tagus Capital 說比特幣有 ETF 管道撐底。那山寨幣和 DeFi 協議的 LP 是不是該立刻重新定價所有依賴「即將立法」敘事的持倉？
  2. 如果下一版法案把大部分 token 歸入 SEC 管轄，現有部署在 Uniswap、Morpho 等協議上的無許可流動性池，技術上要怎麼在智能合約層實作合規過濾而不破壞組合性？

Morpho TVL $11B 的成長故事，核心依賴一個中心化平台決定不切換

事實背景

Morpho 鎖倉總值（TVL，協議內抵押資產總額）逾 $11B，年初至今增近 100%；競爭對手 Aave TVL $16B，年初至今跌近一半，起因之一是 KelpDAO 遭駭造成約 $200M 壞帳。Morpho on Base（Coinbase 孵化的 L2）過去 12 個月從 $2B 增至逾 $4B。Coinbase 的借貸產品讓用戶以 cbBTC（Coinbase 發行的包裝比特幣）為抵押借 USDC，以 Morpho 為主要市場。ETH 年初至今跌 22%，BTC 跌 8%。

So What?

Base 上 $2B 到 $4B 的翻倍與 Coinbase 借貸產品上線時程高度重疊，可合理推斷 Coinbase 通路貢獻了多數增量。靠平台導流獲取的用戶通常沒有獨立留存意願，Coinbase 若切換預設借貸市場，Morpho 的 cbBTC/USDC 那條線的 TVL 蒸發速度取決於用戶是否有獨立意願留下，而這個比例文章未揭露，無法量化。真正的風險不是 Aave 競爭，而是 Coinbase 作為單一分發渠道，讓 Morpho 的「去中心化」標籤存在結構性矛盾。

值得追問
  1. Morpho 如果拿掉 Coinbase 借貸產品導入的 cbBTC/USDC 那條通路，剩下的有機成長和用戶留存率是什麼。Coinbase 哪天切換去 Aave，Morpho 還剩什麼？
  2. Morpho 的 vault curator 模型把風險參數外包給第三方策展人，如果 Coinbase 導入的 cbBTC 抵押品出現脫錨，curator 的清算觸發機制比 Aave 的治理投票制快多少，還是其實更慢？

a16z 拿 buyout 最壞年份對比創投最好年份，這是論述選擇，不是分析失誤

事實背景

a16z 合夥人 Martin Casado 11-04 發文，主張科技 buyout（槓桿收購）是晚週期資產。關鍵數字：過去 10 年 US Buyout 年化報酬 14.5%，低於 Russell 3000；US venture 年化 17.6%，高於 Russell 3000 約 2.3 個百分點。前 5% 基金 DPI（已實際分配回 LP 的倍數，以 2007 至 2016 年份計）：創投 5.3x、buyout 3.5x。2021 至 2022 年的軟體 buyout 債務 2028 至 2029 年面臨到期牆，約 $140B 的三分之一已評 CCC+ 以下。Thoma Bravo 以約 $6.4B 收購 Medallia，$5.1B 股權歸零，債權人接管。文末附有免責聲明，a16z 為創投管理人。

So What?

buyout 被用 2021 至 2022 這段最差年份檢視，創投的 5.3x DPI 用的卻是 2007 至 2016 年份，刻意略開了創投自己的 2021 年份。創投 2021 年份在低流動性環境下同樣幾乎沒有已實現退出，TVPI（含未實現估值的總倍數）仍以未流通估值支撐，若 LP 要求 a16z 拿出自家 2021 年份基金的 DPI，數字幾乎肯定會打穿這篇文章的結論框架。讀懂這個不對稱的 LP 是贏家，把這篇文章當客觀研究而非募資材料的人是輸家。

值得追問
  1. a16z 拿 buyout 2021–22 最爛年份對比創投 2007–16 最好年份，如果 LP 反問 a16z 自己 2021 年份基金的 DPI 和未實現減記幅度，數字會不會一樣難看？
  2. PE 軟體資產 2028 年到期牆 $140B 若觸發批量出售，買方最可能是有現金的 hyperscaler 而非創投。這對 a16z 投資組合公司的定價權是結構性利多，還是代表退出通道被大廠壟斷？

Fal $16B 估值成立的前提是毛利率顯著高於它自己點名的每一個同業

事實背景

舊金山 AI 推論（inference，執行已訓練模型的運算）新創 Fal 完成 $1.3B 融資，Bessemer Venture Partners 領投，Nvidia、Sound Ventures、T. Rowe Price 參與，估值 $16B，較 4 月的 $8B 翻倍。年化營收今年稍早突破 $800M，估值約為年化營收 20 倍（自行計算，營收時點較早，實際倍數可能偏低）。同業 Baseten、Fireworks AI、Modal 的毛利 TechCrunch 明確指出偏薄。Fal 本身毛利未揭露。

So What?

20 倍年化營收是否合理取決於毛利率。若 Fal 毛利率與同業相近（推論為 20 至 40%），20 倍營收等同 50 至 100 倍毛利，接近 SaaS 軟體的高端估值，但底層是算力租賃而非軟體邊際成本。Bessemer 要讓這個估值成立，需要 Fal 的毛利率顯著高於同業，或年化營收在交割前已繼續快速增長，兩者均未披露。

值得追問
  1. $16B 估值除以「今年稍早」的 $800M 年化營收是 20 倍，但 TechCrunch 自己說同業 Baseten、Fireworks AI 毛利偏薄。如果 Fal 也在同一個毛利率區間，Bessemer 實際上買的是多少倍毛利？
  2. Nvidia 同時是 Fal 的算力供應商和本輪投資人。如果 Nvidia 把 NIM 微服務做成端到端托管，Fal 的推論調度層還剩什麼技術護城河不能被上游直接複製？
