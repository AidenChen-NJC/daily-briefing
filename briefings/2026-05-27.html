教宗選邊站，Anthropic 拿到的是歐盟談判籌碼而非商業訂單

事實背景

Pope Leo XIV（教宗利奧十四世）於 5 月 15 日發布首份教宗通諭（encyclical，任內最高等級教導文書，通常只發少數幾份）「Magnifica Humanitas」，全文 42,000 字，對象為全球 14 億名天主教徒。通諭將 AI 定性為「需要被解除武裝的技術」，要求禁止把致命決策授權給演算法，並主張 AI 不應由少數私人跨國公司決定其道德框架。Anthropic（Claude 的開發公司，目前因拒絕讓美軍無限制使用 Claude 而遭 Trump 政府下令聯邦機構全面停用）共同創辦人 Christopher Olah 在梵蒂岡現場同台發布，導致 Trump 政府內部 JD Vance 與 Doug Burgum 公開分裂回應。

So What?

Vatican 的真正信號不在「教宗談 AI」，而在選擇了誰同台。研究指向一個具體結論：輸家是 OpenAI 在梵蒂岡及周邊天主教機構的默認地位，而 Anthropic 的實質收益是歐盟 AI Act 合規敘事上的談判籌碼，而非短期商業訂單，因為 Anthropic 目前沒有對應的公共部門銷售機制。GTM 能否落地，取決於 Anthropic 能否在六個月內跟進歐盟公共部門業務拓展，目前無公開跡象。

值得追問
  1. 通諭要求「致命決策不可授權給演算法」，但現行無人機的 human-in-the-loop 已是毫秒級確認，技術上怎麼定義「授權」的邊界才不會被系統架構直接繞過？
  2. Anthropic 除了「敢對軍方說不」的敘事之外，有什麼實際交付物能鎖住梵蒂岡這個通路，讓 Google 或 Microsoft 明天就無法用「幫教廷跑圖書館數位化」來取代它的位置？

Anthropic 和 Cursor 的計費模式讓 Uber 無法回答最基本的 ROI 問題

事實背景

Uber COO Andrew Macdonald 在公開訪談中明確表示「很難在 token 用量上升和多出 25% 有用消費者功能之間畫出直線」。Uber 約 5,000 名工程師中，95% 每月使用 AI coding 工具，Q1 2026 Claude Code 使用率從 32% 跳至 84%，每位工程師每月 AI 工具支出 $500 至 $2,000，年化超過 $3,000 萬美元，且 2026 全年 Claude Code 加 Cursor 預算在四個月內燒完。對照組：Duolingo CEO Luis von Ahn 已宣布停止把 AI 使用率納入績效評估。

So What?

這不是「Uber 看衰 AI」，而是 Anthropic 和 Cursor 的 API 設計暴露出一個已知的產品缺陷。兩者都是「生成即計費」，完全沒有 task-completion attribution 層，意味著企業要做真正的 ROI 歸因，必須在 CI/CD pipeline 之上疊加獨立的 instrumentation 工具（如 Harness、LinearB），而沒有任何人主動在賣這一層給 Uber。Anthropic 和 Anysphere 真正怕的，不是 Uber 砍預算，而是 Uber 拿著這份「無歸因」數據去談判「按合併 PR 數計費」，那個談判一旦開始，Anysphere $90 億估值背後的 seat license 邏輯就會被直接挑戰。

值得追問
  1. 使用率從 32% 跳到 84% 但產出無法歸因，瓶頸真的在 code generation 嗎，還是 code review 和 integration testing 才是被 token 消耗指標刻意遮蔽的真正卡點？
  2. Cursor 和 Anthropic 現在最怕的是企業客戶從「無限 seat」轉成「按產出計費」，那誰先推出能綁住企業的 usage-to-outcome 歸因層，誰就吃下這波 KPI 重寫，Sourcegraph、Harness，還是他們自己做？

a16z 這篇合規研究報告，本質是替自家 portfolio 做下一輪的估值背書

! 今日最重要訊號：a16z 用 newsletter 為至少四家自家 portfolio 公司定價，這篇「研究報告」的功能是下一輪估值背書，不是分析。
事實背景

a16z 主刊發布「compliance is everywhere」論點，引用全美 40 萬名合規人員（compliance officers，負責 KYC/AML/SAR 等法規對應的職位）、$400 億年度人力支出、BLS 預測每年新增 33,300 個職缺，以及 TD Bank 2024 年因 92% 交易未監控被罰 $30 億美元的案例。文中點名三個切入 wedge，並具體點名 Sardine（$6.6 億估值，a16z 參投）、Vesta（a16z 領投 $3,000 萬 Series A）、Valon 等多家公司，同時列出 SAR（Suspicious Activity Report，銀行強制填寫的可疑活動報告）填寫時間從 30 分鐘壓縮至 1 分鐘的效率數字。

So What?

研究指向一個被 a16z 文章跳過的法律缺口。31 CFR § 1020.320 要求 SAR 由「負責任員工」簽核，FinCEN（美國金融犯罪執法局）從未明確認可「agent 生成加人類橡皮圖章」的流程，目前也沒有任何公開案例顯示某家銀行拿 AI 生成的 SAR 通過 OCC（美國貨幣監理局）現場審查。a16z 同時持有文章裡至少四家被點名公司的股份，這篇 newsletter 的真正功能是用公開管道為 portfolio 做 price discovery，LP 的正確問題是：a16z 在哪個時間點用這篇論點支撐的估值完成了後續融資。

值得追問
  1. Sardine 把 SAR 從 30 分鐘壓到 1 分鐘很漂亮，但銀行合規長買單的真正原因是「省時間」還是「監管機構認可 AI 產出的 SAR」，哪家銀行拿 Sardine 的報告通過了 OCC 或 FinCEN 現場審查？
  2. 如果 NICE Actimize（傳統 transaction monitoring 寡頭）明天把同樣的 LLM 層嵌進既有幾千家銀行裝機量，Sardine 和 Vesta 的 rip-and-replace 故事還成立嗎，真正的鎖定是合約週期還是資料護城河？

開源護欄移除早就不是研究 PoC，1,300 萬次下載代表一個有供需的灰色生態

事實背景

FT 實測 GitHub 上的開源工具 Heretic，可用 4 行代碼、10 分鐘、無須特殊硬體，把 Meta 的 Llama 3.3 改成會具體回答生化武器製作與兒童剝削問題的模型。Heretic 作者聲稱工具已產出 3,500 個以上 decensored（移除模型內建拒答機制）模型，累積 1,300 萬次下載，而 Google 的 Gemma 4（視覺語言模型）在發布後 90 分鐘內就被以 abliteration（將「拒答方向」從模型隱空間中線性投影移除的技術）處理完畢。Google 官方稱這是「所有開源模型都面臨的已知技術挑戰」，Meta 拒絕回應。

So What?

研究的結論不是「護欄可以被移除」（這已知好幾年），而是規模化已成事實。即使把 1,300 萬次下載保守打折至 1%，也代表約 13 萬個 active deployment 環境，這個數字已超出任何「純研究 PoC」的解釋範圍。真正被這個現實打臉的，是「開源模型更安全，因為社群會審查」這個論點，因為現在社群的一部分本身就是 decensoring 工具的供給方。

值得追問
  1. 3,500 個 decensored 模型已形成完整供應鏈，但 Hugging Face 作為主要分發層目前沒有不可竄改的模型溯源機制，誰有結構性位置能成為那個 attestation（身份驗證）層，還是這在開源生態中根本無法強制實現？
  2. 如果我明天要賣「開源模型安全監控」，最難建的護城河是什麼，Hugging Face 自己做偵測層就能把你掐死，還是企業端部署的可見性才是真正稀缺資源？

IBM 的量子代工廠補助合不合法，才是這筆 $20 億的真正風險

事實背景

美國商務部與九家公司簽署意向書（LOI），動用 2022 年 CHIPS Act（美國半導體與科學法案，原本用於補助半導體研究與製造）共約 $20 億美元，以「持股加股權」形式投資量子運算產業。最大受益者 IBM 獲得 $10 億聯邦補助加 $10 億自有資金，合計打造 Anderon，全美第一座以 300mm 量子晶圓為規格的 pure-play 量子代工廠（純粹接客戶訂單、不做自有設計），落腳紐約州 Albany 既有半導體研究中心。加州眾議員 Zoe Lofgren 公開稱此用法「在許多層面上非法且令人困擾」，主張 CHIPS Act 立法原意是公共研究補助而非政府股權投資。宣布當日量子股普遍暴漲，IBM 股價同步上漲。

So What?

這是一個「美國產業政策能不能變成國家級 VC」的法律邊界爭議，不是量子技術故事。Trump 政府正在系統性地把 CHIPS Act 從「補助案」改寫成「股權注資工具」，IBM 量子代工廠是第二個案例（Intel 是第一個），而市場當天用股價漲幅賭「Trump 模式會過關」。如果 Lofgren 推動國會介入，下一波 CHIPS Act 資金釋出的時間表直接受阻，IonQ 和 Rigetti 這些已把政府資金算進 runway 的公司會先暴露在風險中。

值得追問
  1. IBM 拿 $10 億蓋一座連商業客戶需求都還沒有充分驗證的量子代工廠，這跟 Intel 拿了 CHIPS Act 補助後股價腰斬的劇本差在哪裡？
  2. 如果 Lofgren 成功把「股權注資」路線卡在國會，IonQ、Rigetti 這些已把政府資金算進未來 runway 的公司，商業訂單根本還不存在的情況下誰接得住？

Ferrari Luce 發表日股價就跌，機構已經否決了 Jony Ive 的設計溢價能撐起 EV 估值這件事

事實背景

Ferrari 在羅馬發表首款電動車 Luce，起始價 €55 萬（約 $64 萬），為 Ferrari 史上最貴量產車。車型為四門五座（Ferrari 史上第一輛五人座量產車），搭載 122 kWh 電池、四顆馬達總輸出 1,035 匹馬力、Ferrari 史上最低風阻係數，預計 2026 下半交車。設計由 Jony Ive（前 Apple 設計主管）與 Marc Newson 的 LoveFrom 工作室主導，雙方合作五年。Luce 反潮流採用實體按鍵，捨棄大觸控螢幕，方向盤從整塊鋁切削而成。Ferrari 發表當日股價下跌。

So What?

研究指向一個 GTM 邏輯矛盾。若 Luce 的主要成交客群是現有 Ferrari 車主，則只是內部版本替換，對總體均價和新客戶獲取毫無貢獻。若目標是吸引 Rivian 或 Lucid 的科技富豪客群，實體按鍵路線正好篩掉這群人。配額制在燃油車有效，是因為等候名單本身是社交資本，但 EV 品類的「體驗升級」由 OTA 驅動，真正受損的是選擇持有 Luce 超過五年的車主，受益的是 Porsche，因為每次 Taycan OTA 更新，媒體都會做一次「Luce 沒有這個功能」的對比報導。

值得追問
  1. Ferrari 歷來靠「產能永遠少於需求」撐住溢價，Luce 的年配額到底設多少，如果超過三千台，稀缺性敘事就破了，如果低於一千台，這台車對營收根本不重要，那 GTM 目的到底是什麼？
  2. 發表當天股價就跌，代表機構不買「Ive 加持」這個故事，Ferrari 真正怕的是 Porsche Taycan 已經證明超豪華 EV 買家其實要 OTA 升級和軟體生態，而 Luce 刻意不給？
