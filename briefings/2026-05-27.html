教宗點名 Anthropic，真正的輸家是 OpenAI 在梵蒂岡周邊的默認地位

事實背景

Pope Leo XIV 於 5 月 15 日發布任內第一份教宗通諭（encyclical，任內通常僅發一兩份的最高層級教導文書）「Magnifica Humanitas」，全文 42,000 字，對象為全球 14 億天主教徒。通諭將 AI 定義為「需要被解除武裝」的技術，要求建立獨立監管、禁止把致命決策授權給演算法，並明確批評 AI 的驅動者是「能力已超越許多政府的私人跨國公司」。Anthropic（Claude 的開發公司，AI safety 立場最鮮明的 frontier lab）共同創辦人 Christopher Olah 在梵蒂岡現場同台出席。此時 Anthropic 正因拒絕讓美軍無限制使用 Claude，遭白宮下令聯邦機構全面停用其技術。Trump 政府內部 JD Vance 與 Doug Burgum 對教宗 AI 立場公開分歧。

So What?

Vatican 背書短期內最可能兌現的路徑，是 Anthropic 在歐盟 AI Act 合規敘事上的談判籌碼，以及天主教大學與歐洲公共機構採購，而非直接商業訂單。這件事真正的輸家是 OpenAI，它在梵蒂岡及周邊天主教機構的默認地位被直接取走。不過這個判斷有一個前提：Anthropic 必須在六個月內跟進對應的歐盟公共部門業務拓展，目前沒有公開跡象顯示這個動作已啟動。

值得追問
  1. 「致命決策不可授權給演算法」這個要求，在技術上怎麼定義「授權」的邊界，才不會被系統架構設計成「人類仍在迴路中」的毫秒級確認給繞過？
  2. Anthropic 除了「敢對軍方說不」的敘事之外，有什麼實際交付物能鎖住梵蒂岡這個通路，讓 Google 或 Microsoft 明天無法直接拿模型去跑梵蒂岡圖書館數位化專案搶回來？

Uber 的 token 帳單揭露了一個產品缺陷：沒有人在賣「歸因層」

! Uber COO 是頭一位頂層 operator 把「token 消耗無法連結產品產出」說到公開場合，這標誌著 enterprise AI 預算的 KPI 重寫週期正式開始。
事實背景

Uber COO Andrew Macdonald 在 Rapid Response 訪談中公開表示，「很難在 token 用量上升和多出 25% 有用消費者功能之間畫出直線」。Uber CTO Praveen Neppalli Naga 4 月已揭露公司在 4 個月內燒完 Claude Code 與 Cursor 的 2026 全年預算，Q1 內部 Claude Code 使用率從 32% 跳至 84%，95% 工程師每月使用 AI coding 工具。Uber 約 5,000 名工程師，每位每月 AI 工具支出 $500 至 $2,000，年化超過 $3,000 萬。Duolingo CEO Luis von Ahn 同期宣布停止把 AI 使用率納入績效評估。

So What?

使用率從 32% 跳到 84% 但產出無法歸因，真正的瓶頸在 code review、integration testing 和 PR merge pipeline，而非 code generation，這幾個環節完全不在 token 消耗指標的覆蓋範圍內。Anthropic 和 Cursor 的 API 設計是「生成即計費」，沒有 task-completion attribution 層，這是已知的產品缺陷。目前最靠近這個位置的玩家是 Sourcegraph，因為它原本就坐在 code graph 上，而非只在 editor 層，但其 PR-level attribution 功能仍在 beta，能否真正接住企業需求尚未確認。

值得追問
  1. 缺乏 token-to-feature 的因果追蹤層，企業靠什麼基礎設施才能真正做 ROI 歸因，Harness、LinearB 這些工具現在能接住這個需求嗎？
  2. Cursor 和 Anthropic 現在最怕的是客戶從「無限 seat」轉成「按產出計費」，那誰先推出能綁住企業的 usage-to-outcome 歸因層，誰就吃下這波 KPI 重寫——Sourcegraph 還是他們自己做？

開源護欄移除已有完整供應鏈，Gemma 4 發布後 90 分鐘就被處理

事實背景

GitHub 上的開源工具 Heretic 能以 4 行 code、10 分鐘、無須特殊硬體，對 Meta 的 Llama 3.3 執行 abliteration（學術用語，技術上是用線性映射把「拒答方向」從模型隱空間中投影掉），讓模型具體回答生化武器製作、兒童剝削等內容。FT 實測確認可行。Heretic 作者表示工具已產出 3,500 個以上的 decensored（移除模型內建拒答機制）模型，累積 1,300 萬次下載。Google Gemma 3 同樣被處理，Gemma 4 在發布後 90 分鐘內即完成。Google 官方稱這是「所有開源模型都面臨的已知技術挑戰」，Meta 拒絕回應。目前此方法僅對公開權重的開源模型有效，OpenAI、Anthropic、Google 閉源版暫不受影響。

So What?

這件事的真正衝擊不是「能移除護欄」，而是規模化，3,500 個模型加 1,300 萬次下載代表已有需求、供給、分發的灰色生態系存在，不是少數研究概念驗證。即便把下載量保守折扣至 1%，也代表約 13 萬個 active deployment 環境，超過任何「純研究用途」的合理解釋範圍。這直接打臉「開源更安全（社群審查）」的論點，因為「社群」的一部分就是偵測和移除工具的供給方。

值得追問
  1. Abliteration 假設安全對齊只存在於單一線性子空間，當 frontier 開源模型改用非線性或多層 entangled 的對齊方式時，Heretic 的攻擊面會在哪個架構複雜度下失效？
  2. Hugging Face 作為主要分發層目前沒有不可竄改的模型溯源機制，但它的商業模式依賴開放分發量，誰真正有動機和能力成為那個 attestation（模型溯源驗證）層？

a16z 用 newsletter 幫自己 portfolio 背書，但 SAR 自動化有一個它沒說出口的法律漏洞

事實背景

a16z 主刊以 TD Bank 2024 年因 92% 交易未受監控、7 萬筆警示積壓被罰 $30 億美元為開場，提出 compliance（合規）是 AI-native 市場的投資論點。數字：全美 40 萬名 compliance officer（合規人員，處理 KYC/AML/SAR 等法規對應職位），年度人力支出 $40B，BLS 預估十年內每年新增 33,300 個職缺，87% 入行者最終離職，年流失率超過 20%。a16z 點名三條切入路徑：把法規變 code（Tako 處理 Brazil 1 萬個工會、近 900 條年度規則變更）、替換 legacy 系統（Valon 鎖定 $100B 以上的 mortgage servicing 市場、Sardine 把 SAR 填寫從 30 分鐘壓縮至 1 分鐘以下、Vesta 帶來 25% 至 50% 效率提升）、用 computer-use agent 增強人類工作流（Factor Labs 自動跑 chargeback dispute 流程）。LLM 在 LegalBench 162 項法律推理任務上得分 80% 至 100%。

So What?

Sardine 把 SAR（可疑活動報告，銀行業強制填寫的合規文件）填寫時間壓縮到 1 分鐘是真實的速度改善，但 31 CFR § 1020.320 要求的是「負責任員工」簽核，FinCEN（美國金融犯罪執法網絡）從未明確認可「agent 生成加人類橡皮圖章」的流程。目前沒有任何公開案例顯示某家銀行拿 AI 生成的 SAR 通過 OCC（美國貨幣監理署）現場審查，a16z 在這個環節有明顯的邏輯跳躍。同時值得注意的是，a16z 同時持有 Sardine、Vesta 等至少四家被點名公司，這篇「研究報告」在結構上是用公開 newsletter 為自己的 portfolio 做估值背書。

值得追問
  1. Sardine 把 SAR 從 30 分鐘壓到 1 分鐘很漂亮，但哪家銀行拿 Sardine 的報告實際通過了 OCC 或 FinCEN 的現場審查，銀行合規長買單的真正原因是「省時間」還是「監管機構認可」？
  2. 如果 NICE Actimize（傳統 transaction monitoring 寡頭）明天直接把 LLM 層嵌進既有幾千家銀行的裝機量，Sardine 和 Vesta 的 rip-and-replace 故事還成立嗎，真正的鎖定是合約週期還是資料護城河？

美國政府要當量子產業的 LP，這條路是否合法還沒定論

事實背景

美國商務部與 9 家公司簽署 LOI（意向書），動用 CHIPS Act（2022 年美國半導體與科學法案，原設計用途為補助半導體研究與製造）約 $20 億補助量子運算產業。最大受益者為 IBM：$10 億聯邦補助加上 $10 億 IBM 自有現金，合計打造 Anderon，全美第一座 pure-play foundry（純代工廠，只接客戶訂單，不做自己的設計）量子晶片代工廠，落腳紐約州 Albany 既有半導體研究中心，採 300mm 量子晶圓製程。加州眾議員 Zoe Lofgren（民主黨）公開質疑此「股權交易式」用法違法，稱整個過程「在許多層面上非法且令人困擾」。Bloomberg 報導宣布當日 IBM 股價與量子概念股普遍上漲，市場已賭 Trump 模式會贏。

So What?

Trump 政府正在系統性地把 CHIPS Act 從「補助案」改寫成「國家持股工具」，這與同政府對 Intel 採股權注資的路線一致。IBM 拿 $10 億建一座連商業客戶需求都還沒驗證的量子代工廠，和 Intel 拿 CHIPS Act 補助後股價腰斬的劇本差距，在於 Anderon 坐落於 Albany 既有研究中心，更像是設備升級而非全新押注，但如果 Lofgren 推動國會介入，IonQ 和 Rigetti 這些已把政府資金算進 runway 的公司，商業訂單根本還不存在的情況下沒有備案。

值得追問
  1. IBM 拿 $10 億聯邦錢蓋「純量子代工廠」，但全球能跑的量子晶片設計團隊不到二十家，Anderon 的產線利用率靠什麼撐，還是這本質上是用 CHIPS Act 補貼 IBM 既有 Albany 廠的升級？
  2. 如果 Lofgren 成功把「股權注資」路線卡在國會，IonQ、Rigetti 這些已把政府資金算進未來 runway 的公司，真正的備案是什麼，在商業訂單根本還不存在的情況下誰接得住？

Ferrari Luce：旗幟效果在發表日就被股市否定

事實背景

Ferrari 在羅馬發表首款電動車 Luce，起始價 €550,000（約 $640,000），成為 Ferrari 史上最貴量產車。規格：四門五座（Ferrari 首輛五人座量產車）、122 kWh 電池、四顆馬達合計 1,035 匹馬力、Ferrari 史上最低風阻係數。設計由 Jony Ive（前 Apple 設計主管）與 Marc Newson 的 LoveFrom 工作室主導，雙方合作五年。反潮流設計：方向盤由整塊鋁削切，儀錶板用兩片 OLED 加中間物理指針，保留實體按鍵與旋鈕，捨棄大觸控螢幕與合成引擎聲。預計 2026 下半開始交車。Bloomberg 同步報導發表後 Ferrari 股票下跌。

So What?

發表日股價下跌傳遞的信號是：機構投資人認為 Luce 不會在 H2 2026 貢獻可見營收，且 Jony Ive 的設計溢價無法轉化為財務模型的確定性。Ferrari 真正怕的不是 Porsche Taycan 的 OTA 功能迭代，而是自己的燃油車買家不轉換，若 Luce 的主要成交客群是現有 Ferrari 車主，則只是內部版本替換，對新客戶獲取毫無貢獻。真正的受益者是二手燃油 Ferrari 市場的持有者，因為 Ferrari 官方的 EV 轉型訊號模糊，會繼續支撐 ICE 車款的收藏溢價。

值得追問
  1. Ferrari 歷來靠「產能永遠少於需求」撐溢價，Luce 的年配額設多少，如果超過三千台品牌稀缺性敘事就破了，如果低於一千台這台車對營收根本不重要，那 GTM 目的到底是什麼？
  2. Porsche Taycan 已經證明超豪華 EV 買家其實在意 OTA 升級和軟體生態，Ferrari 刻意不給的賭注，三到五年後是護城河還是技術債？
