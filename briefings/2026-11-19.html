OpenAI 說 agent 產出值兩倍薪水，算出來只是把 API 帳單換了名字

事實背景

OpenAI 是 ChatGPT 的開發商。它 11-18 發布內部報告〈Research acceleration: The jagged frontier〉，稱 coding agent（能自己寫程式、跑實驗、改錯的 AI 代理）不經人介入完成「人類需 2 至 4 小時」研究任務的比例，從 3 月 23% 升到 10 月 46%，4 至 8 小時任務從 13% 升到 35%。各類任務落差很大：監控訓練 run 成功率 79%，寫推論與 serving 程式碼只有 25%。研究員每天 agent 花費中位數 $2,400，比 9 月多 62%，這個數字按 API 牌價（公開定價，不是內部實際成本）計算。OpenAI 估 agent 產出約等於研究員非股權薪酬的兩倍，股權佔目標薪酬 70% 至 80%，不計入。報告同時呼籲立法，要求實驗室公開遞迴自我改進（AI 協助開發下一代 AI 的回饋迴圈）指標。所有數字皆為 OpenAI 自評，方法中途有更新。

So What?

研究指向一個結論：「兩倍薪酬」不是獨立量出來的產出，而是牌價花費換了個說法。$2,400 乘約 250 個工作日約 $60 萬一年，股權佔薪酬七到八成，剩下非股權部分的兩倍剛好落在這附近。真正的產出價值仍然未知，要等 Anthropic 揭露 API 毛利率才能反推牌價和實際成本差幾成，這個推論信心中等。

值得追問
  1. 這 $2,400 是按牌價算的，內部邊際成本可能低一個數量級。Anthropic 掛牌後揭露的 API 毛利率，會不會直接拆穿「價值等於兩倍薪酬」這個說法？
  2. 研究員說願意砍 40% 人力換 agent，這只是問卷上的偏好，還是真的有哪個 pretraining 團隊砍了人之後產出沒掉？

Tencent 的雲端年增 35%，可能有一塊是自己付給自己

事實背景

Tencent 是微信與 QQ 的母公司，也是中國最大的遊戲商。它 11-18 公布 Q3 營收 RMB207.3B、年增 8%，但非 IFRS（排除股權報酬、投資損益等的調整後數字）營業利益 RMB68.1B，年減 6%，利潤率從 38% 降到 33%。扣除新 AI 產品（Hy、元寶、CodeBuddy、WorkBuddy、小微）後，營業利益為 RMB83.3B、年增 8%，代表 AI 產品一季拖累約 RMB15.2B。雲端營收年增 35%，馬化騰稱由 WorkBuddy 帶動，後者 DAU（每日活躍用戶）超過 1,000 萬，每天消耗超過 100 兆 token。自由現金流（營業現金流扣掉資本支出）為負 RMB69.1B，公司歸因於「大額預付算力採購」，排除後為正 RMB16.9B。同期 Oracle 取消可取得約 10 萬顆 AI 晶片的租約，美國也收緊東南亞資料中心服務中國客戶的規則。

So What?

100 兆 token 除以 1,000 萬 DAU，等於每人每天 1,000 萬 token，這遠超過聊天的用量，只可能是 agent 型的背景運算或企業後端呼叫。就算用每百萬 token RMB1 的極低成本估，一季也約 RMB9B，和 AI 產品拖累的 RMB15.2B 同一量級，所以號稱由 WorkBuddy 帶動的雲端成長，可能有相當部分是 Tencent 內部付給自己的消耗。算術可靠，但成本單價與內部轉撥比例是假設，信心中等。

值得追問
  1. 那筆約 RMB86B 的預付到底付給了誰？如果有相當部分落在跟 Oracle 同類的海外設施，Q4 的減值風險是不是早就坐在資產負債表上了？
  2. WorkBuddy 的千萬 DAU 裡，有多少是微信生態內預裝灌出來的零付費企業員工？補貼和入口一拔，還剩幾成？

Binance 的凍結令凍不住比特幣，但能把駭客每個變現出口變成關卡

事實背景

Binance 是全球最大的加密貨幣交易所。它 11-18 取得阿布達比國際金融中心法院（ADGM，採英國普通法）$6.5B 全球凍結令（禁止被告處分全球資產的禁制令），追討 10-29 被駭資產，律師稱可能是史上最大。約 $6.34B 受影響資產中，約 $2.85B 已被凍結或攔截。Elliptic 估約 $3.3B 留在 BTC、ETH、XRP 上，「沒有人能凍結」。Binance 說穩定幣發行商與交易所在釋出凍結資金前需要法院命令，並維護一份 26,000 個錢包地址的「living list」。Binance 已先用公司資金承擔客戶損失。

So What?

研究指向一個結論：這張令的真正用途不是凍結現有資產，而是把未來每一個出口變成可執行點。那 $3.3B 的 BTC、ETH、XRP 遲早要經過交易所、場外交易或換成穩定幣才能變現，有了 26,000 個地址清單加上法院命令，任何收到這些資產的中心化對手方都得配合，而 Elliptic 說穩定幣重新發行給 Binance 需要的「明確法律依據」，就是這張令。贏家是 Tether 這類可凍結的發行商，輸家是駭客的變現路徑。

值得追問
  1. 剩下 $3.3B 沒人能凍，Binance 真正的策略是等駭客換成穩定幣再攔，還是這張凍結令主要是拿來對保險公司和客戶交代？
  2. 駭客終究得經過交易所或跨鏈橋才能變現，但在 26,000 個地址的規模下，哪些混幣協議或跨鏈路徑是現有追蹤工具系統性追不到的？

MARA 不靠 AI 租約也付得起利息，真正的風險是那個 $144M 獲利預估

事實背景

MARA Holdings 是美國最大的上市比特幣礦商。它 9 月後以均價約 $81,039 賣出 13,597 顆比特幣，約 $1.1B，其中 $750M 用來償還以比特幣擔保的貸款（拿 BTC 抵押借錢，幣價跌會被追繳保證金）。11-18 它以 8.75% 利率發行 $185M 新債，支應約 $1.5B 收購 Long Ridge Energy & Power，標的是俄亥俄州一座 485MW（百萬瓦）天然氣電廠與超過 1,600 英畝土地，計畫轉型為 AI 運算園區。加上 Long Ridge 既有 $600M 票據，合計 $785M 債務，年息約 $68.7M。資料中心租約一份都還沒簽，可能延到 2027。Long Ridge 2026 前九個月營收 $178.5M、淨損 $3.5M，MARA 以 2025 下半年推估其年化調整後盈餘為 $144M。

So What?

「租約沒簽，拿什麼還債」這個疑問前提不太成立，電廠本身賣電就有現金流，$144M 對 $68.7M 年息約 2.1 倍覆蓋，短期償債不靠資料中心。真正的風險在 $144M 本身，它是用 2025 下半年推估的，而 2026 前九個月實際是淨損。電價一跌、租約又拖到 2027，覆蓋倍數會很快收窄，這個判斷信心中等。

值得追問
  1. MARA 賣幣避開了約 $250M 跌價，但「挖到不賣」正是當初投資人買股的理由。它現在到底是礦業公司、電力公司，還是一檔拿比特幣波動做方向性交易的對沖基金？
  2. 從囤幣礦商變成 AI 房東，護城河是那 485MW 的併網電力，還是只要有錢誰都能在俄亥俄買電廠？QTS、Vantage 在搶同一批租戶，MARA 憑什麼排前面？

Anthropic 史上最大 IPO，三分之一的錢是供應商在預付自己的營收

! 史上最大 IPO 的需求裡，有三分之一來自會把錢收回去的供應商。
事實背景

Anthropic 是 Claude 模型的開發商。它 11-18 把 IPO 定價在每股 $83，高於原區間 $70 至 $78，發行量從 8.25 億股上調（upsize）到約 9.8 億股，募得 $81.3B，超過 SpaceX 的 $75B，成為史上最大 IPO。完全稀釋市值（把選擇權、可轉債全部換成股票後計算的市值）約 $1.5T，11-19 以代號 ANT 在 Nasdaq 交易。Google、Microsoft、Nvidia、AMD 等合計以 IPO 價認購 $26B，約佔募資 32%。招股書顯示九個月營收 $33.24B、年增約 1,200%，10 月底年化營收約 $81B。淨損 $104B，主要來自可轉債公允價值變動（估值上升時帳上認列的非現金虧損）。

So What?

Anthropic 年化營收 $81B，一年付給算力與雲端供應商的錢幾乎肯定超過 $26B，所以這筆認購在功能上更接近供應商融資，不是獨立的市場需求。贏家是 Nvidia、AMD、Google、Microsoft，它們既以 IPO 價拿到股權，又鎖住了未來營收。輸家是把首日超額認購當成純市場熱度的散戶，而最大持股者 Amazon 不在具名認購名單裡，同樣值得注意（信心中等，招股書的算力採購承諾金額本次未見）。

值得追問
  1. 這 $26B 裡，有多少會在十二個月內以雲端與晶片採購的形式，流回這四家公司的營收？
  2. Ondo 上市當天就發 ANTon 給海外投資人 24/7 交易，它真正想搶的是 Anthropic 的價格發現權，還是借 ANT 的名氣替自家平台導流？
CNBC · WSJ · Reuters VC

Palo Alto 付的 38% 溢價，只在它自己股價不回檔時才存在

事實背景

Palo Alto Networks 是全球最大的資安公司。它 11-18 宣布以 $4.5B 全股票（以收購方股票支付，不付現金）收購 Applied Compute，這家新創幫企業運行與客製開源權重模型（公開參數、企業可自行部署微調的模型，如 Llama、Qwen）。WSJ 稱 Applied Compute 本月估值 $3.25B，換算溢價約 38%，它的營收、客戶與創辦人資訊在所有來源都沒有揭露。CEO Nikesh Arora 說「這可能比我們現在做的還大」。同晚 PANW 公布 Q1 營收 $3.44B、年增 39%，全年營收指引上調到 $14.52B 至 $14.57B。股價盤後漲超過 7%，今年以來漲 85%。

So What?

如果 PANW 股價回到年初水準，這筆 $4.5B 的股票只值約 $2.43B，比 Applied Compute 本月 $3.25B 的估值還低。「38% 溢價」只在 PANW 現價下成立。全股票支付把回檔風險整包轉給賣方，若 PANW 真被高估，PANW 股東是贏家，Applied Compute 股東是輸家（信心中等，實際發行股數與定價基準日未揭露）。

值得追問
  1. Anyscale、Together、Baseten，甚至客戶自己的平台工程團隊，明天都能幫企業部署開源模型。Applied Compute 手上到底有什麼獨佔的企業合約或資料飛輪？
  2. 如果 PANW 真正買的是團隊，鎖定期有多長？核心的人走了之後，還剩什麼？
