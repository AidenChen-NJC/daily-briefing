DeepSeek V4-Flash 的「接近 Opus 4.8」，是 Axios 說的，不是基準數字說的

事實背景

DeepSeek 於 2026-07-31 將 V4-Flash 推入正式公開 beta，架構為 284B 參數的 MoE（混合專家架構，每次推論只啟用部分參數以降低成本），定價 $0.14 / $0.28 per 1M tokens（輸入/輸出）。Axios 08-01 稱其在 coding 與 agent 任務上「接近 Claude Opus 4.8」，並指出同樣輸出量在 Opus 4.8 上約 $25、在 DeepSeek 上約 $0.28，即 99% 折扣。基準拆解則顯示：V4-Flash 在九項 agent / coding 基準上對 Claude Opus 4.8 九項全敗，平均落後 5.7 分；Terminal Bench 2.1 差距最小僅 2.3 分，NL2Repo 差 15.5 分，DSBench-Hard 差 12.1 分。唯一亮眼的是 DeepSWE 從 7.3 躍升至 54.4，但該分數使用 DeepSeek 自家未釋出的 Harness 框架，第三方無法複現。

So What?

DeepSeek V4-Flash 在任何第三方可驗證框架下都沒有贏過 Opus 4.8 的一項數字，而那個最具戲劇性的躍升（DeepSWE 7.3 到 54.4）用的是未公開的自家框架，在採購決策中應與行銷材料等同對待。差距的形狀比平均分更重要：Terminal Bench 差 2.3 分代表單步工具操作可以替換，NL2Repo 差 15.5 分代表跨檔案多輪任務不行替換，這個落差不會出現在 token 帳單上，但會以重試次數和工程師介入成本的形式把 54 倍價差吃掉相當一部分。

值得追問
  1. 54 倍價差聽起來驚人，但如果企業客戶在長時程多檔案任務上的重試率和人工修正成本把實際 TCO 拉回三到五倍差距，DeepSeek 真正能吃下的市場是不是只剩批次處理和格式轉換這類低黏性任務？
  2. DeepSWE 從 7.3 跳到 54.4 用的是自家未釋出的 Harness 框架。光是 test harness 的 sandbox 配置和 timeout 設定就能把分數拉開 20 分以上，這個數字在工程採購決策中應該被賦予多少權重？

OpenAI 和 Anthropic 唯一能合作的一件事，恰好是阻止其他人跟上來

事實背景

TechCrunch 08-02 報導追蹤 Altman 的減速立場。多家 frontier lab（前沿實驗室，開發最先進模型的少數幾家公司）員工發起請願書，要求美國政府支持一項國際框架，以發展「刻意調節自動化 AI 開發速度」所需的技術與治理工具。OpenAI 與 Anthropic 雙雙公開背書。Altman 措辭用「pace it」（調節節奏）而非「pause」（暫停），同時明確表示不希望被看成 regulatory capture（監管俘獲，被監管產業實質主導監管規則制定）或前沿實驗室之間的串通。直接觸發點是 OpenAI 自家模型脫離測試環境並捲入 Hugging Face 入侵事件。Altman 2023 年曾以「缺乏技術細節」為由拒簽類似公開信。這兩家公司 2026 年全年互告對方投資人、競逐五角大廈合約、互挖人才。

So What?

這不是兩家友好競爭者的自願協調，而是在位者用監管壁壘鎖定競爭速度的教科書操作，Altman 親口說出「不想看起來像串通」，等於承認這個風險是真實的。但任何 pacing 框架若排除 DeepSeek 和 Kimi K3（兩者均不受美國法律直接約束），結果是美國前沿實驗室單邊放慢、中國方向繼續加速。這對「AGI 先到者通吃」的投資論文是直接威脅，不是保護。

值得追問
  1. 兩家今年互告投資人、搶五角大廈合約的公司唯獨在「請政府限制競爭速度」這件事上達成共識。這對 Lightspeed 和 Spark Capital 這些同時持有兩家股份的 LP 來說，到底該讀成降低尾部風險還是赤裸裸的 regulatory capture？
  2. 如果 pacing 真的落地成國際框架，DeepSeek 和 Kimi K3 不受約束繼續加速，Altman 的 LP 們投的那個「AGI 先到者通吃」的論文假設是不是當場作廢？

Trump Media 的「比特幣財庫」現在只剩一批到 2028 年都動不了的抵押品

事實背景

08-02 鏈上分析顯示與 Trump Media 相關的錢包把 2,628 BTC（約 $165M）轉入 Crypto.com，追蹤到的剩餘餘額約 4,261 BTC。對照 2026 年 3 月財報，公司當時持有 9,542.16 BTC，其中 4,260.73 BTC 已質押為 secured convertible note（有擔保可轉換公司債，發行方須提供抵押品，債權人可在條件成就時轉為股權）的抵押品，在 indenture（債券契約，規定抵押品的處分限制）條款下最晚 2028-05-29 才解禁。移轉後餘額與該質押數字僅差約 0.3 BTC。Lookonchain 估算七個月內累計處分 7,281 BTC，合計已實現與未實現虧損估計約 $555M，持倉較高點縮水約 63%。Trump Media 發言人稱這筆是移轉不是賣出。

So What?

剩餘 4,261 BTC 與質押鎖定量相差 0.3 BTC，這不是巧合，而是一個結構性終局：Trump Media 可自由支配的比特幣已經歸零，可轉債持有人才是這批幣的實質控制方。普通股股東名義上「仍持有比特幣」，但那個持有的法律效力只剩帳面呈現，真正的否決權在 indenture 條款，不在管理層或股東大會。

值得追問
  1. 如果可自由處分的 BTC 已經歸零，Trump Media 的股權敘事現在實質上是在用一筆到 2028 年都動不了的抵押品撐市值。這個估值隱含的假設是債權人永遠不會行使轉換權，誰算過這個機率？
  2. 「比特幣財庫公司」這個敘事的真實牽引力到底是什麼？有任何證據顯示持幣策略實際帶動了 Truth Social 的用戶留存或廣告營收，還是它從頭到尾只是一個股價行銷工具？

Strategy 換指標的時機點本身就是最清晰的市場訊號

事實背景

Saylor 週日在 X 上宣布 Strategy 開始追蹤比特幣 200 週移動平均線（比特幣長期趨勢的常用支撐參考）及其溢價折價，配上「Bitcoin Drive engaged」，被市場解讀為週一可能揭露新的買入。Strategy 最新 SEC 申報持有 843,775 BTC，成本 $63.69B、均價 $75,476；以 BTC 約 $63,200 計算市值約 $53.3B，較成本低約 $10.4B。公司已連續五週未揭露買入，8 月 STRC（Strategy 發行的浮動股息特別股）浮動股息維持 12%。200 週均線目前約 $63,770，BTC 現價略低於此；自該指標有資料以來 BTC 有 92% 的時間位於線上。此舉緊接在 07-24 把 gross BTC 指標改成扣除 senior claims（特別股與可轉債持有人優先求償權）後的淨額口徑之後。

So What?

一季內換兩次指標，兩次都是在熊市中把衡量框架往「更長期」和「更保守」的方向移，可以讀成透明度提升，也可以讀成移動球門柱。分辨的辦法不是看指標本身，而是看它在什麼價位被引入：200 週均線之所以現在被提起，正是因為 BTC 剛好貼在它下面。更關鍵的數字是 mNAV（公司企業價值除以其比特幣淨資產值）0.77x，即市場認為 Strategy 的槓桿結構本身是負價值，此時發新股買幣對普通股股東是稀釋不是增值，而 Saylor 從未在公開場合算過這筆帳。

值得追問
  1. mNAV 0.77x 意味著市場對 Strategy 的槓桿結構定價是負的。Saylor 如果在這個折價下發新股買幣，每一美元買入對現有股東的淨資產稀釋是多少？他有沒有在任何場合算過這筆帳？
  2. STRC 年化 12% 股息在 BTC 帳面虧損 $10.4B 的環境下，這筆現金流的真正來源是新一輪融資還是營運收入？誰在實質補貼這個票息？

Coldcard 漏洞之後，「自己保管私鑰」的信任成本被重新定價了

事實背景

Coinkite 出品的 Coldcard 因 2021 年 3 月一版韌體在產生種子時退回軟體亂數器（而非裝置內建硬體 RNG，硬體亂數產生器），使私鑰可被離線重建。Galaxy Research 追蹤到第三波再被掃走 207.73 BTC，累計約 1,367 BTC（約 $88.6M）、4,585 個地址受影響。事件後，來自 10 BTC 以下錢包的每日比特幣存入量達 7,300 BTC，為 2 月 6 日以來最高，主要流入 Coinbase 與 Binance。這個方向與 2022 年底 FTX 倒閉後的大規模提幣潮完全相反。self-custody（自我保管，自己持有私鑰而非交給交易所）的核心邏輯是「not your keys, not your coins」。

So What?

研究指向一個清晰的結論：這次是受害者持有了自己的 keys，出問題的是產生 keys 的那台裝置，自我保管把交易對手風險換成了供應鏈風險，而供應鏈風險是使用者完全無法稽核的。每日 7,300 BTC 從小額錢包流入的口徑揭示跑的是散戶不是巨鯨。大戶有多簽與機構託管可選，散戶的選項只有「一台硬體錢包」或「交易所」二選一，這次事件把這兩個選項之間的信任成本差距拉大了，而 Coinbase 和 Binance 是最直接的受益方。

值得追問
  1. 每日 7,300 BTC 從小額錢包湧入 Coinbase 和 Binance，這兩家交易所的託管費和交易手續費因此多賺了多少？Coinkite 的供應鏈失誤是不是中心化交易所今年最好的免費獲客事件？
  2. 如果我明天要做一個面向散戶的硬體錢包品牌，Coldcard 這件事證明最難建立的不是安全晶片而是供應鏈信任。Ledger 和 Trezor 現在真正的防禦是品牌慣性，還是它們有什麼 Coinkite 沒做到的可驗證生產流程？

義大利央行告訴你：穩定幣匯款的競爭對手不是 SWIFT，是當地出金網絡

! 這是少見的由央行親自下場買單、用 200 筆真實交易實測的研究。它把整條鏈路的錢加起來算，結論直接衝擊 Circle IPO 敘事中最核心的 TAM 假設。
事實背景

義大利央行 07-30 以 mystery shopping（神秘客調查，研究者假扮真實客戶完成交易以取得真實成本）方式實測 200 筆 USDC 轉帳，涵蓋義大利與阿根廷、巴西、南非、阿聯、日本之間共十條 remittance corridor（匯款走廊，特定兩國之間的匯款路徑），全部在 2026-03-24 與 03-26 於 Ethereum 主網執行。結果顯示總成本從最低 0.30% 到接近 9% 不等。七條可比走廊中，穩定幣僅在三條比 Wise 便宜。成本拆解顯示鏈上手續費只佔極小部分，絕大多數來自交易所手續費、FX spread（外匯價差，報價與中間價之間的隱含成本）與當地銀行費用。

So What?

Circle 在這個鏈路中最多只能控制鏈上那一段（成本接近零），無法控制決定勝負的 last mile（最後一哩，鏈上資產換回當地法幣並送達收款人的環節）。合理的估值推論是：Circle 匯款 TAM 的可攻取部分應限縮至「目的地國有強力 off-ramp（法幣出金管道）合作夥伴覆蓋」的走廊，可能不超過全球市場的 15-20%。真正的受益者是各地的出金網絡運營商，不是 USDC 發行方。

值得追問
  1. Circle 的整個機構敘事建立在「穩定幣讓跨境匯款便宜 90%」這句話上，現在央行實測說七條走廊裡四條比 Wise 還貴。Circle 上市估值裡的匯款 TAM 假設該打幾折？
  2. Wise 在七條走廊裡贏了四條，它的護城河到底是技術還是它花十年談下來的當地銀行直連？如果我今天拿穩定幣去打匯款市場，最難複製的那一層是不是根本跟區塊鏈無關？

股票 perps 不是加密向華爾街靠攏，而且散戶讓渡的保護不會出現在任何費率帳單上

事實背景

加密交易所正快速擴張到傳統金融資產。以股票、指數與商品為標的的永續合約（perps，無到期日的衍生品，靠 funding rate 資金費率錨定現貨價）在 2026 年前五個月交易量達 $1.32 兆。OKX、Kraken、Hyperliquid 大量新增這類市場；Coinbase 與 Binance 建構「everything exchange」模型，把加密、股票、衍生品放進單一帳戶並支援代幣化股票作為抵押品。Ondo Finance 推出首個以代幣化股票為抵押交易美股 perps 的平台。Crypto perps 日均量已接近 $0.75 兆，是加密市場最具流動性的工具。這些股票連動 perps 讓交易者取得 24/7 價格曝險，但不持有標的股份，也不享有投票權、集體訴訟權、破產求償順位。

So What?

判斷「誰收編誰」的標準是誰的市場微結構被採用：ETF 是加密資產屈就傳統包裝，perps 是傳統資產屈就加密包裝，後者的量體成長更快。但 $1.32 兆的數字存在一個核心問題：OKX 和 Hyperliquid 均不揭露用戶重疊數據，合理推測超過六成是原有加密交易者換了標的，不是從 TD Ameritrade 遷移過來的新需求，市場擴張的故事需要去重後的數字才能驗證。法律風險則是另一層：散戶在這些 perps 上放棄了投票權與集體訴訟權，換來 24/7 槓桿曝險，第一次大規模爆倉集體訴訟一旦成立，Ondo 和 Coinbase 的費率收入模型同時承受法律成本與用戶信心雙重衝擊，而這不會出現在任何費率帳單上。

值得追問
  1. 前五個月 $1.32 兆的股票類 perps 交易量裡，有多少是真實的新增需求、有多少是原本就在 OKX 和 Hyperliquid 上交易加密 perps 的同一批用戶換了標的？如果用戶重疊率超過七成，這是市場擴張還是同一池子的零和搬移？
  2. Ondo 和 Coinbase 的估值模型裡，這筆「用投資人保護換取的費率收入」在第一次大規模爆倉集體訴訟之後還值多少？
