Anthropic 從 $97 跌回 $83 的路上，沒有任何買盤會接

! 史上最大 IPO 的股價下方，接下來一個月是真空地帶。
事實背景

Anthropic 是開發 Claude 模型的 AI 公司。11-18 以 $83 定價，高於原本 $70 至 $78 的區間，發行 9.8 億股、募資 $81.3B，11-19 在 Nasdaq 以代號 ANT 掛牌。開盤 $111.50，較承銷價高 34%。收盤 $97.17，漲 17%，但比開盤價低約 13%，成交量逾 8.46 億股。收盤完全稀釋市值（把選擇權等全部換成股票後計算的市值）約 $1.8T，排名美國第 7。承銷商握有綠鞋（超額配售權，可在上市後加賣最多約 1.47 億股、約 $12.2B），期限 11-20。指數納入（被加入指數後，被動基金必須買進）的時程是 Morningstar 美國全市場指數 5 個交易日後，Nasdaq-100 要 12-18 之後，S&P 500 至少一年。同日 Nasdaq-100 跌 2.21%，S&P 500 連六黑，道瓊跌 1,084 點。

So What?

綠鞋只有在股價跌破 $83 時才會托底，現在收盤 $97，承銷商會直接向 Anthropic 行使選擇權，讓 Anthropic 多拿約 $12.2B，Goldman 與 Morgan Stanley 再多收一筆費用。所以 $97 到 $83 這 15% 的區間沒有任何機制撐盤，11-20 綠鞋到期後，連 $83 這道防線也消失。下週唯一的被動買盤只剩規模很小的 Morningstar 指數納入。

值得追問

  2. 綠鞋 11-20 到期，Nasdaq-100 要 12-18 才納入，這中間一個月沒有被動買盤，配到首日股票的 LP 是不是已經在排減持時程？

Nvidia 的 $500B 沒放出去，被拒絕的是 neocloud 的信用

事實背景

Nvidia 是全球最大的 AI 晶片供應商。2026 年 8 月它與 Apollo、BlackRock、Blackstone、Brookfield、Goldman Sachs、KKR 簽備忘錄（MOU，表達合作意向但沒有出資義務的文件），目標動員逾 $500B 借給買 Nvidia GPU 蓋資料中心的業者，Nvidia 稱可擔保最多 $125B，約 25% 的晶片殘值（保證設備日後至少值多少錢，跌破由擔保人補差額）。WSJ 11-18 報導，三個月來平台放款金額為零，第一筆交易不太可能在 2027 年前完成。對照組是 Broadcom 在與 Anthropic 的 $35B 交易中擔保約 85%。Apollo 執行長 Marc Rowan 稱，Nvidia 若不再擔保，大量 neocloud（專門出租 GPU 算力的新興雲端業者，如 CoreWeave，多數信評低於投資級）的資金管道「會消失」。主導計畫的黃仁勳上週辭去執行長，由 Colette Kress 代理。

So What?

25% 對 85% 的差距，比較像是擔保對象的信用差距，Broadcom 背書的是剛募到 $81B 現金的 Anthropic，Nvidia 平台要背書的則是信評多半低於投資級的 neocloud。CoreWeave、Lambda 也沒辦法改找 Broadcom，因為那 85% 是跟著 Anthropic 的信用走，可行的路是先簽下 Anthropic 或 OpenAI 的長約、用實驗室的信用去借錢，等於從雲端業者降級成房東。贏家是議價權大增的 Anthropic 和能拉高利差的 Apollo、KKR，輸家是沒有錨定租戶的二線 neocloud。

值得追問
  1. Nvidia 連 50% 殘值都不敢簽，它自己模型裡三年後 H200 等級 GPU 的殘值到底假設是多少？
  2. neocloud 的算力租約通常比 GPU 折舊週期短很多，黃仁勳離開後，這個期限錯配的信用風險現在由誰來判斷？

銀行用一份合約，把 AI agent 的護城河搬到自己家

事實背景

Citi、PNC、Citizens 本月更新客戶條款，客戶若授權第三方 AI agent（能代替使用者登入、下單、轉帳的 AI 程式）存取帳戶，造成的損失由客戶自負，包括 agent 被駭的情況。JPMorgan 與 Bank of America 10 月已採類似立場，美國至少五家大銀行對齊，PNC 條款 11-18 生效。據二手報導，Citi 新增的 Section H 把「用交給外部 agent 的帳密進行的活動」一律視為客戶授權，但 Citi 自家的 AI agent 不在此限。法律爭點是 Regulation E（美國電子資金轉帳規則，限制消費者對未授權轉帳的損失責任）。CFPB（消費者金融保護局）與 OCC（貨幣監理署）至今沒有公開回應。

So What?

條款鎖定的是交給 agent 的帳密，在這種存取方式下，銀行看到的登入不論來自 agent 還是駭客都一模一樣，技術上無法區分，所以乾脆把所有交易事先定義成「已授權」。結果是護城河由合約築成而不是技術，做出金融 agent 不難，難的是拿到一份銀行簽字、責任分配清楚的存取協議，最快的路可能是去當某家銀行的白牌 agent。輸家是仍靠帳密爬取的第三方 agent 與中小型金融 agent 新創，這個格局只在 CFPB、OCC 繼續沉默時成立。

值得追問
  1. 如果 OpenAI 和 Anthropic 的 agent 因此打不進消費金融，它們投影片上的 TAM 要砍掉多少？
  2. 有沒有哪個開放協議，像 A2A 或 MCP，能在技術上讓 agent 身份可驗證，讓銀行沒辦法只靠合約條款壟斷存取權？

DeepSeek 的 ¥615.5B 買的是國家隊席位，不是現金流

事實背景

DeepSeek 是以開源模型聞名的中國 AI 實驗室。據 The Information 報導，它完成第二輪約 ¥105.5B（約 $15.8B）融資，近 30 家投資人參與，Tencent 與 CATL 領投，投後估值（含本輪新資金後的公司估值）約 ¥615.5B，換算約 $84.6B 至 $92B。國資（國有資本）比重從第一輪約 2% 升到約 27%。據 BigGo 轉述，Tencent、CATL 各持股約 9.57%，中國移動、中信證券各投資 7.65%，其他合夥人包括 NetEase、美團、吉利、美的、vivo、IDG、博裕。創辦人梁文鋒退出直接持股，改經 99% 持有的顧問公司控制，並委任中信證券評估科創板（上交所專為科技公司設立的板塊）上市。

So What?

公開資料裡沒有 DeepSeek 的營收或利潤，任何 DCF（現金流折現估值）都撐不起這個數字。投資人幾乎都是要部署模型的公司，中國移動、吉利、美的、vivo、騰訊買的是優先接入權和國家隊席位，Tencent、CATL 各約 9.57% 的持股也是策略卡位的規模。和每天在 Nasdaq 被重新定價的 Anthropic 不同，這個估值從沒經過價格發現。

值得追問
  1. 上市後國資 27% 加上中信做券商，模型權重要不要開源到底誰說了算？開源承諾有什麼機制能防止被單方面收回？
  2. 如果你在中國做 AI infra，被收編進國資體系的 DeepSeek 會變成你非接不可的壟斷通路，還是會因為上市合規而失去迭代速度？

代幣化 IPO 輸的不是技術，是 Goldman 的配售名單

事實背景

Binance Wallet 是全球最大加密交易所 Binance 的錢包服務。11-18 它開放用 USDC（Circle 發行的美元穩定幣）認購代幣化股票（鏈上發行、價格追蹤真實股票的代幣）形式的 Anthropic IPO 股份，$500M 上限數小時內額滿。最後只拿到約 2,957 股，以 $83 計約 $245K，滿足率約 0.05%。Binance 全額退回約 5 億 USDC，並把這 2,957 股加上 $1M 的 ANTB 代幣按比例空投（免費發到用戶錢包）給認購者。Bitget 取得 153,774 股，只滿足 1.3% 的認購。Kraken 的 xStocks 不保證配售，Ondo 的 ANTon 只提供價格曝險。6 月 SpaceX IPO 時，Binance、Bybit、Bitget Wallet 也是全數退款。

So What?

$500M 幾小時填滿證明需求是真的，0.05% 的滿足率證明通路是假的，最難複製的不是鏈上基礎設施或經紀商牌照，而是被承銷銀團列進配售名單的關係與資產規模。Kraken 有合規架構仍不保證配售，連一半下單的機構都空手而回，現行制度下沒有任何技術能繞過 Goldman、Morgan Stanley 的配售裁量權。贏家是只做次級市場價格曝險的 Ondo 與 Kraken xStocks，輸家是用「讓散戶搶 IPO」當賣點的平台。

值得追問
  1. 滿足率 0.05%，SpaceX 那次也全額退款，Binance 和 Bitget 一再這樣做，圖的是手續費、新用戶，還是單純拿「代幣化 IPO」當行銷？
  2. 一級市場入口被承銷商鎖死這件事不解決，還有哪個 LP 該往 RWA（真實世界資產上鏈）代幣化的下一輪放錢？

Pantera 的深圳遊記，結論剛好站在它的美國持股那一邊

事實背景

Pantera Capital 是老牌加密創投，11 月月信記錄團隊在深圳待一週、訪談人形機器人產業鏈的觀察。Pantera 稱中國佔去年全球人形機器人產量逾 90%。Omdia 統計 2025 年約 13,000 台交付中 87% 在中國製造，AgiBot 以 5,168 台、39% 市佔居首。當地高管自評軟體落後海外一到兩年，基層工程師直說軟體不能用，中國廠商仍建在 OpenAI、Nvidia、Physical Intelligence 的開源模型上。地方政府補貼資料農場（雇人重複操作以蒐集機器人訓練資料的場所），Pantera 認為重複資料邊際價值低，真正的護城河是把資料轉成訓練訊號。

So What?

Pantera 明說它接觸或投資的每家美國機器人公司都依賴中國供應鏈，而它點出的缺口「資料、標註、智能」，正好落在這些美國公司所在的軟體與資料層。「吃苦文化讓利潤趨近零」對買硬體的美國公司是利多，對 AgiBot 這類中國硬體公司的股東是警訊，Pantera 站在買方。至於資料農場只能改善窄任務的判斷，研究信心低，目前只有 Pantera 單一來源，沒有任何基準測試。

值得追問
  1. 如果你是 Physical Intelligence 或 Figure，現在對中國硬體供應鏈的依賴到底多深？有沒有任何一家美國機器人公司已經用非中國供應商跑通量產？
  2. 開源模型繼續免費的話，中國軟體追上只是時間問題，那 Pantera 說的「訓練訊號護城河」到底在哪家公司的資產負債表上？
