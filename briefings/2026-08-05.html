白宮框架的第一個效果：幫閉源廠商造了一道開源競品永遠貼不上的合規標籤

事實背景

白宮於 08-04 邀集 OpenAI、Anthropic、Meta、Google 檢視一份依 Trump 2026-06-02 行政命令設計的自願性框架，規定上述公司可在模型公開發表前最多 30 天讓政府取得存取權，模型須存放於高安全性環境、存取留詳細 log。Axios 取得的框架文本顯示，「covered frontier model」被定義為閉源、具最先進能力且有國安風險的模型，Qwen3.8-Max、Kimi K3 等開放權重模型被明文排除。框架全文不對外公開，基準測試列為機密。

So What?

閉源廠商為這份框架付出的實際成本接近零：30 天禁售期只有在模型有硬發布日時才有機會成本，而 OpenAI 和 Anthropic 的發布節奏本就是滾動式。真正的收益是企業銷售層面的品牌標籤，政府背書讓「受監管」變成一個可對 CISO 報銷的採購理由，而 Kimi K3 和 Qwen3.8-Max 永遠無法貼上這個標籤。這是一次零成本的市場分割，不是安全框架。

值得追問
  1. 如果我是一家用 Qwen 或 Llama 開權重模型出貨的 AI 新創，這份框架等於替我免除了所有合規成本，那閉源廠商實際上要靠什麼 GTM 動作，才能讓企業客戶覺得「被監管」是值得多付錢的功能，而不是交期延遲的風險？
  2. 框架「自願加保密」意味著合規無法被外部稽核，OpenAI 和 Anthropic 真正願意配合的動機，是拿到「政府背書安全」的品牌溢價做企業銷售，還是單純在用 30 天禁售期當護城河擋開源競品？

Qwen 開放 2.4 兆參數：Anthropic 的企業客戶手上現在有一個用不到但能用來砍價的錨點

事實背景

Alibaba 發表 Qwen3.8-Max，一個 2.4 兆參數稀疏 MoE（混合專家架構，每個 token 只啟動其中少數「專家」子網路）模型，每個 token 只啟用 950 億參數，context window（模型單次能讀入的 token 上限）為 100 萬 tokens。Model Studio 定價為 input $2 / output $6 每百萬 tokens，較 Anthropic Fable 5 約為其五分之一，較 OpenAI GPT-5.6 Sol 未快取 input 便宜 60%、output 便宜 80%。在 Arena WebDev 排行榜上領先 Anthropic Fable 5。完整權重預計 8/10 於 Hugging Face 釋出，這是 Qwen Max 系列首次開放權重。

So What?

阿里真正的 GTM 不是鼓勵人自架，是用「開放權重存在」這件事壓低 Model Studio API 的議價阻力。2.4 兆參數的自架門檻（記憶體、互聯頻寬）使絕大多數企業無法真正部署，但它讓 Anthropic Fable 5 的企業客戶手上有了一個可公開引用的比價錨點，即使從未打算切換，談判桌上的籌碼已經換邊。能擋住切換的真正防線不是模型品質差距，是企業合規認證（SOC 2、HIPAA、歐盟資料主權）、已完成的 fine-tuning pipeline 以及 support SLA，這些都是 Qwen 開放權重版本目前無法提供的配套。

值得追問
  1. Anthropic 上一輪估值 $600 億的核心假設是閉源模型能長期維持定價權，現在 Qwen3.8-Max 用 Fable 5 五分之一的價格在 WebDev 排行榜上領先，Anthropic 的 LP 該用什麼數字重算那個估值的合理性？
  2. 如果我今天用 Fable 5 或 GPT-5.6 Sol 出貨一個 AI 產品，客戶拿 Qwen 的公開價格來砍我，我實際能防守的點是什麼，是模型品質差距，還是純粹的切換成本和合規認證，哪一個才是真正擋住客戶搬走的牆？

OpenAI Astra 的真實邊界是它比 Fable 多解出的那五題，而不是「AI 會做數學了」

事實背景

OpenAI 公開 Astra（尚未正式發表的下一代模型），宣布解出 10 個橫跨數學、量子複雜度與理論計算機科學的開放問題，每題至少開放十年。最受矚目的包括構造出 Gromov 自 1999 年提出後懸置的非 sofic 群（sofic 群指其行為可被有限置換系統任意逼近，非 sofic 群的存在性約三十年無解），以及否證 Alain Connes 關於 von Neumann 代數的 rigidity conjecture。OpenAI 釋出 249 頁手稿與 Lean 4（形式化證明語言，其 kernel 對證明只有接受或拒絕兩種結果）證明憑證於 GitHub，repo 的 `sorry`（Lean 中標記「此處未證明」的佔位符）計數為 0。依 Sol API 費率，所有成功執行的 token 成本合計約 $2,000。十項結果均未經同儕審查。24 小時內，Anthropic 的 Levent Alpoge 宣稱用 Fable、通用 prompt、無網路連線重現了其中五項。

So What?

Lean 驗證推導合法性，但不驗證 Lean 陳述是否忠實對應原始數學問題。若任何一題的 Lean 定理陳述把原始問題弱化為平凡形式，機器驗證通過但數學主張失效，OpenAI 的「AI 做研究」敘事將從最可信（有機器錨點）變成最危險（有機器背書的錯誤）。Alpoge 明確說無網路、通用 prompt，排除了工具調用的解釋，因此 Astra 若真有邊際能力，最可能是更大的推論 token 預算，而不是架構突破，這對「下一代模型」的估值敘事有結構性影響。

值得追問
  1. 如果 Anthropic 的 Levent Alpoge 用已經上架的 Fable 和通用 prompt 就能在 24 小時內重現一半，那 Astra 真正不可複製的邊際能力是落在剩下那五題的難度差距，還是只是 OpenAI 先跑了一遍知道哪些題可解，如果是後者，這展示的是模型能力還是選題策略？
  2. 十題零同儕審查、Lean 只驗推導不驗命題陳述是否平凡，如果其中任何一題事後被發現是把定理寫成了 trivially true 的形式化，OpenAI 為 Astra 建立的「AI 做研究」定價錨點會一夜歸零，哪家 LP 現在該對這個風險重新定價？

金融業 91% 在替 AI 技能加薪、77% 看不到 ROI：這是選擇權定價，不是生產力定價

事實背景

PwC 調查超過 1,000 位美國金融服務業 director 級（總監級）以上高管。86% 表示對許多新進人員而言，AI 技能訓練比 MBA 更有價值。91% 正在提高具 AI 技能員工的薪酬，58% 願意為 AI 熟練度（指實際操作能力而非理論知識）支付溢價。近八成高管預期公司員工數在未來五年內縮減至少 20%，入門級與中階職位最易受衝擊。但 77% 表示多數 AI 投資尚未展現可衡量的 ROI（投資報酬率，指能歸因到具體財務科目的效益）。

So What?

91% 加薪但 77% 沒有可衡量 ROI，這組數字只有一個內部一致的解釋：HR 預算在吸收選擇權保費，P&L 上找不到對應的效益歸因。企業買的是「萬一 AI 重要時我手上有人」的保險，而非生產力，真正能成交的 AI upskilling 產品 pitch 是「留才保險」而非「ROI 計算器」。更深的結構矛盾在於：8 成預期裁減入門級、86% 說要訓練新人，被訓練的入門級不是為了被留下，而是為了在被裁之前產生足夠的標註資料和回饋信號來訓練取代他們的系統。

值得追問
  1. 91% 加薪但 77% 沒看到 ROI，如果我現在要賣一套 AI upskilling 產品進金融業，真正能成交的 pitch 是「幫你產生可衡量的 ROI」還是「幫你的 AI 人才不被隔壁挖走」，客戶實際在買的到底是生產力還是留才保險？
  2. 八成高管說五年內砍兩成人力、入門級最脆弱，但同時說要大量訓練新人 AI 技能，這兩個訊號擺在一起，真正會發生的 GTM 機會是不是「取代入門級人力的 AI agent 產品」而不是「訓練入門級人力的課程產品」？

蒙大拿的實驗藥物執照：發照者的收入和發照數量正相關，這不是監管放寬，是監管私有化

事實背景

依 2025 年 5 月由 Gianforte 州長簽署的 Senate Bill 535，蒙大拿讓任何持有實驗性藥物的生技公司有一條直售通路：藥物只要通過 Phase I（第一期臨床試驗，只驗證安全性與耐受劑量，不驗療效，有時受試者少至 10 名健康人），公司即可支付 $12,500 向新設立的審查委員會申請核准。委員會由長壽創業者 Niklas Anzinger 籌組，經費完全來自申請費，成員包含一名蒙大拿州認證醫師、專家科學家與一名倫理學家。核准後公司可自行定價，透過診所販售，首批診所預計 2026 年底前開業。與其他 right-to-try（試藥權法，允許特定患者取得未經核准藥物）不同，蒙大拿不要求患者為末期病患。委員會核准不等同 FDA 核准，不賦予任何聯邦法律地位。Anzinger 同時在宏都拉斯 Próspera 特許區經營販售實驗性幹細胞與基因療法的診所。

So What?

委員會的收入與發照數量正相關，而否決的代價（損失 $12,500 且申請者不再來）由委員會自己承擔，批准的代價（患者受害）由患者承擔。Phase I 只驗證急性毒性，委員會沒有任何獨立資料能否決一份通過了 Phase I 的申請，激勵結構使否決的制度性動機趨近於零。這條 GTM 通路的實際存續期估計是三到五年，終結點不是 FDA 的法律行動，是第一起媒體報導的患者傷害事件觸發蒙大拿州議會廢法。
